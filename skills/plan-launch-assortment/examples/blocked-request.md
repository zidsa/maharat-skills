# مثال توقف صادق

طلب التاجر: «اختر لي 20 منتجًا من كتالوج المورد» مع أسماء وصور فقط، ومن دون تكاليف أو MOQ أو زمن توريد أو متطلبات سلامة أو دليل طلب.

النتيجة الصحيحة: لا تصنّف أي منتج أساسيًا أو تجريبيًا ولا تخترع كمية شراء. سجّل كل منتج بوصفه **مؤجلًا**، واطلب بطاقة المورد والاقتصاديات والقيود التنظيمية ودليل الطلب. يمكن اقتراح اختبار اهتمام غير بيعي بعد تحديد العميل والمناسبة فقط.
