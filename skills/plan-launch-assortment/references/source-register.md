# سجل المصادر

| المصدر | الاستخدام | الرابط |
|---|---|---|
| Zid Docs — Products | فهم بنية المنتج والحقول والمتغيرات عند تجهيز كتالوج زد | https://docs.zid.sa/products-1934287f0 |
| Zid Docs — Start Here | الرجوع إلى توثيق المنصة الرسمي ومسارات الموارد الحالية | https://docs.zid.sa/start-here |
| Google Search Central — Ecommerce site structure | بناء تصنيف وروابط تساعد اكتشاف المنتجات، دون استخدامه بدل قرار التشكيلة | https://developers.google.com/search/docs/specialty/ecommerce/help-google-understand-your-ecommerce-site-structure?hl=en |
| Google Search Central — Ecommerce best practices | مراجعة متطلبات بيانات المنتجات وتجربة الاكتشاف | https://developers.google.com/search/docs/specialty/ecommerce |
| منشآت — كتالوج أدوات التجارة الإلكترونية | موارد رسمية مرتبطة بالتخطيط والتشغيل للتجارة الإلكترونية | https://www.monshaat.gov.sa/sites/default/files/2024-12/Toolkit_Catalogue_AR.pdf |
| الهيئة العامة للغذاء والدواء — إدراج منتجات التجميل | عند كون المنتج تجميليًا في السعودية، تحقق من متطلبات الإدراج وصور المنتج والملصق وقائمة المكونات بدل الاكتفاء بقول «شهادة سلامة» | https://www.sfda.gov.sa/ar/eservices/88819 |
| الهيئة العامة للغذاء والدواء — مراقبة ادعاءات التجميل | تجنب تحويل ادعاء تجميلي إلى ادعاء طبي غير مسموح، ووجّه للمصدر الرسمي | https://www.sfda.gov.sa/ar/faq/60280 |

افحص تاريخ الاطلاع لأن واجهات المنصة وحقولها قد تتغير. مصدر المنصة يشرح ما يمكن تمثيله تقنيًا؛ قرار الإطلاق يجب أن يعتمد على بيانات التاجر والمورد.

إذا كان المنتج غذاءً أو دواءً أو تجميلًا أو جهازًا أو منتجًا منظمًا آخر، استخدم الجهة الرسمية الخاصة بالسوق ونوع المنتج. لا تعمم قواعد مستحضرات التجميل على غيرها.
