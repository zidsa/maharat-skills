# قائمة المدخلات

## اطلب من المستخدم

- الهدف المطلوب والمدة الزمنية.
- نطاق المتجر أو المنتجات أو الطلبات المعنية.
- معيار النجاح المتوقع.
- القيود التجارية أو النظامية أو قيود العلامة.

## الصلاحيات والبيانات التي قد تحتاجها

- [ ] قراءة إعدادات المتجر
- [ ] قراءة المنتجات والكتالوج
- [ ] قراءة الطلبات
- [ ] قراءة التحليلات
- [ ] إنشاء مسودات دون نشر تلقائي

## قبل البدء

- [ ] تأكد أن البيانات تخص المتجر الصحيح.
- [ ] دوّن تاريخ ونطاق كل مصدر.
- [ ] لا تطلب بيانات شخصية لا تحتاجها المهمة.
- [ ] إذا نقصت معلومة مؤثرة، توقف واطلبها بدل التخمين.
