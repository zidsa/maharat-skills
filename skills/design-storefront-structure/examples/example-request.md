# طلب مثال

متجر سعودي جديد يخطط لإطلاق غسول واحد فقط، بينما السيروم والمرطب مؤجلان إلى ما بعد التحقق من الطلب. لدينا سجل أولي للغسول وسياسة شحن مسودة، لكن شريحة العميل والمناسبة الشرائية ووعد المتجر واللغة واتجاه الواجهة لم تعتمد بعد. أريد بنية متجر يمكن للفريق البدء منها دون نشر المنتجات المؤجلة، ودون اختراع جمهور أو فوائد أو تصنيفات لا تثبتها البيانات.
