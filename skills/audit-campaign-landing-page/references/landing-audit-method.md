# منهج تدقيق صفحة الحملة

## الموانع الأساسية

- العرض في الصفحة لا يطابق الإعلان أو المصدر المعتمد.
- CTA يقود لوجهة خاطئة أو حلقة أو خطأ.
- المنتج أو المجموعة غير متاحة بوضوح.
- المعلومة التي تغيّر قرار الشراء مخفية حتى بعد CTA.
- تجربة الجوال تمنع القراءة أو الضغط.

## الشدة

- **مانع:** يمنع فهم العرض أو إكمال الخطوة التالية.
- **مرتفع:** يخلق شكًا أو تكلفة مفاجئة أو تضاربًا.
- **متوسط:** يبطئ الفهم لكن توجد طريقة واضحة للمتابعة.
- **منخفض:** تحسين لا يغير القرار وحده.

اربط كل مشكلة بلقطة أو نص أو URL ووقت فحص.
