# مثال توقف صادق

طلب التاجر: «المبيعات نزلت 18٪ هذا الأسبوع، السبب الإعلان» مع إجمالي مبيعات أسبوعين فقط، بينما تغيّر تعريف الطلب المكتمل ولم تنضج مستردات الأسبوع الأحدث.

النتيجة الصحيحة: ارفض نسبة السبب والمقارنة الحالية. اطلب فترتين متساويتين وتعريفات موحدة وأعداد الجلسات والطلبات والإيراد والخصومات والمستردات الناضجة والتكاليف المتغيرة. سجّل «غير كافٍ للحكم» بدل نسبة الانخفاض إلى الإعلان.
