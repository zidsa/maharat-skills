# منهج الفرز

## ترتيب الاستثناءات

1. خطر مالي أو أمني مثبت.
2. طلب مدفوع لا يمكن الوفاء به.
3. وعد تسليم مهدد.
4. طلب صريح من العميل.
5. تعطل داخلي لا يهدد وعدًا بعد.

الحقيقة المرصودة تصف الحقل وتوقيته: «الدفع pending منذ 09:15». التفسير يحتاج دليلًا إضافيًا: لا تكتب «البوابة معطلة» من طلب واحد.

## توجيه القدرة التالية

| النوع | القدرة التالية |
|---|---|
| دفع غير محسوم | مراجعة سجل بوابة الدفع يدويًا |
| مخزون غير محجوز | `guard-sellable-inventory` |
| تنفيذ متعثر | `monitor-order-fulfillment` |
| شحن مهدد | `detect-shipping-delay` |
| طلب عميل | `draft-customer-service-response` |
| بيانات متعارضة | مالك مصدر الحقيقة قبل أي إجراء |

صيغة `action_key`: `<order_id>:<observed_state>:<cutoff_iso>`.
