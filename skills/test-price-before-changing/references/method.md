# منهج اختبار قرار السعر

## معادلة مبسطة

هامش المساهمة المبسط = سعر البيع بعد الخصم - تكلفة المنتج المتغيرة - رسوم الدفع - دعم الشحن - تكلفة متغيرة مؤكدة أخرى.

هذه ليست صافي الربح إذا كانت تكلفة الإعلان أو المرتجعات أو الضريبة أو التغليف خارج الحساب. سمِّ ما استُبعد بوضوح.

## ترتيب الاختبار

1. ثبّت المنتج والسوق والعملة.
2. افحص هل السعر هو المشكلة أم أن العميل لا يفهم المنتج أو الشحن أو العرض.
3. غيّر متغيرًا واحدًا على نطاق صغير: السعر أو الشحن أو الحزمة، لا كلها.
4. أوقف التجربة إذا تجاوزت الحارس الذي اعتمده التاجر.

## تعريف النجاح

قرار سعر قابل للرجوع ومقاس بالهامش والطلب، لا تخفيض دائم مبني على التخمين.
