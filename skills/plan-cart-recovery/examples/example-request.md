# طلب مثال

جهّز استرجاع سلة لعملاء واتساب الموافقين. نعد السلة متروكة بعد ساعتين، والشحن المجاني معتمد حتى 17 أغسطس. أبغى رسالة ومتابعة واحدة بدون كشف بيانات العملاء.

المنتجات قد تنفد أثناء الحملة، لذلك استبعد أي سلة تغير توفرها، ولا ترسل لمن أكمل الطلب من قناة أخرى. قياس النجاح يكون بطلب مرتبط برابط الاسترجاع لا بمجرد فتح الرسالة.
