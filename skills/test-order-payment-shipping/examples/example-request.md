# مثال طلب

اختبر بناء staging لمتجر ملابس بعد تغيير إعدادات الشحن. لدي منتج ومتغير مخصصان للاختبار، وطريقة دفع sandbox موثقة، وصلاحية قراءة سجل الطلب والدفع والمخزون والإشعارات. أريد اختبار النجاح والفشل وعرض الشحن وإشعار العميل والتاجر والإلغاء أو الاسترداد. لا تستخدم أي بيانات عميل أو بطاقة حقيقية، ولا تعتبر صفحة الشكر وحدها دليل نجاح.
