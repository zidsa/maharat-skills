# فاحص الطلب والدفع

لا تجعل «أنشأنا طلبًا» مرادفًا لنجاح الرحلة. اختبر كل مسار مستقلًا واحتفظ بالدليل الموافق لنوع النتيجة.

## سير العمل

1. اقرأ `references/order-test-method.md` و`references/source-register.md`.
2. ثبّت رابط البناء وإصداره وبيئته ووقت الاختبار، ومصادر إعدادات الدفع والشحن والإشعارات.
3. استخدم هوية اختبار صناعية وطريقة دفع اختبارية موثقة أو مسارًا لا يتطلب بيانات دفع. لا تدخل بطاقة أو عميلًا حقيقيًا.
4. نفّذ السيناريوهات المطلوبة منفصلة: طلب ناجح، فشل دفع، عرض شحن، إشعارات، تسليم للتنفيذ، وإلغاء/استرداد.
5. لكل سيناريو سجّل الخطوات والتوقع والنتيجة والدليل. لا تجعل لقطة نجاح الواجهة دليلًا على حالة الدفع في سجل الطلب.
6. طابق الإجمالي والعملة ومعرف الطلب، ثم تتبع حالة الدفع والمخزون والشحن والإشعارات من مصادرها.
7. عند تعذر الاختبار استخدم `blocked` أو `not_tested` وسببًا؛ لا تمرره افتراضيًا.
8. أنشئ JSON وفق `references/order-test-method.md` وشغّل `node scripts/validate-order-journey-test.mjs <test.json>`.
9. سلّم `assets/output-template.md` مع العيوب ومالك إعادة الاختبار.

## الحد الأدنى من المدخلات

- رابط وإصدار وبيئة البناء المراد اختباره.
- منتج ومتغير تجريبيان، عملة، إجمالي متوقع، ومخزون قبل الاختبار.
- وسائل الدفع والشحن ونطاق الخدمة وإعدادات الإشعار الفعلية.
- طريقة اختبار موفر الدفع المصرح بها دون بيانات حساسة.
- صلاحيات قراءة سجل الطلب وحالة الدفع والشحنة والإشعارات.
- مالك لكل نظام ونافذة إعادة الاختبار.

## قواعد ملزمة

- لا تحفظ بريدًا أو جوالًا أو عنوانًا أو بطاقة حقيقية في الملف النهائي.
- نجاح الدفع يحتاج سجل دفع/طلب، لا صفحة شكر فقط.
- فشل الدفع يثبت عدم إنشاء طلب مدفوع وعدم حجز مخزون دائم وظهور مسار استرداد واضح.
- عرض الشحن يثبت الخيار والتكلفة والمدة قبل إتمام الشراء.
- الإشعار يختبر العميل والتاجر منفصلين.
- الإلغاء أو الاسترداد يحتاج سجلًا مطابقًا لمعرف الطلب والمبلغ أو سبب عدم الانطباق.
- لا تغيّر حالة طلب حقيقي. استخدم بيئة أو طلب اختبار يمكن إلغاؤه وفق خطة معلنة.

## عقد المخرجات

1. البناء وبيانات الاختبار الآمنة.
2. السيناريوهات والـassertions.
3. سجل الأدلة.
4. مطابقة الطلب والدفع والقيمة والمخزون.
5. العيوب ومالكوها وإعادة الاختبار.
6. قرار `verified` أو `blocked`.
