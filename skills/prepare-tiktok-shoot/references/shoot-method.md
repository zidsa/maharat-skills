# منهج تصوير الفيديو القصير

## اختيار الفكرة

- **شرح:** عندما يحتاج المنتج طريقة استخدام أو تركيب.
- **اعتراض:** عندما توجد عقبة شراء موثقة من سؤال أو تعليق فعلي.
- **إثبات بصري:** عندما يمكن إظهار الحجم أو الخامة أو المكونات أو النتيجة المباشرة غير المبالغ فيها.
- **فتح صندوق:** عندما التغليف والمحتويات جزء من القرار.

## بنية المشاهد

1. لقطة أولى تشرح سبب المشاهدة دون ادعاء مبالغ.
2. عرض المنتج واسمه بوضوح.
3. خطوتان أو ثلاث تثبتان الفكرة بصريًا.
4. قيد أو معلومة تمنع سوء الفهم عند الحاجة.
5. CTA واحد إلى صفحة صحيحة.

اكتب زمنًا تقريبيًا للمساعدة في التصوير، لا كقاعدة أداء أو ضمان نتيجة.
