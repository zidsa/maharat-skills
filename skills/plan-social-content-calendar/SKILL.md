# مخطّط محتوى المتجر

هذه المهارة توزع العمل المعتمد؛ لا تخترع حملة أو ادعاء منتج، ولا تنشر المحتوى.

## سير العمل

1. اقرأ `references/calendar-method.md` و`references/source-register.md`.
2. اجمع موجزات الحملات المعتمدة، حقائق المنتجات، القنوات، أيام الحظر، والقدرة الأسبوعية لكل دور.
3. حوّل كل هدف إلى أدوار محتوى: اكتشاف، شرح، إثبات، تحويل، احتفاظ أو خدمة.
4. أنشئ سجل أفكار أولًا، ثم اختر ما يدخل التقويم وفق الأولوية والقدرة وتنوع الرسالة.
5. لكل قطعة: معرف، حملة، هدف، زاوية، حقيقة/دليل، صيغة، قناة، CTA، مالك، مراجع، موعد تسليم ونشر، وحالة.
6. لا تعيد نفس الأصل لكل قناة؛ اكتب تكييفًا واضحًا أو قطعة مستقلة.
7. احسب حمل العمل حسب الدور، وانقل القطع الزائدة إلى `المؤجل` بدل تجاوز القدرة.
8. افحص الناتج بـ `node scripts/validate-output.mjs <output.md>`.

## الحد الأدنى من المدخلات

- الفترة والمنطقة الزمنية وأيام الحظر.
- موجزات حملات مع هدف وعرض ومدة.
- حقائق المنتجات والأصول المتاحة وحقوق استخدامها.
- القنوات وصيغها المتاحة في الحساب.
- عدد القطع التي يستطيع كل دور إنتاجها ومراجعتها أسبوعيًا.
- موافقات العلامة والقانون والمنصة المطلوبة.
- حدث القياس أو إشارة النجاح لكل دور محتوى.

## حدود القرار

- لا تضع وتيرة يومية لمجرد ملء الجدول.
- لا تنسخ ادعاءً بلا سجل حقيقة.
- لا تعتبر «التفاعل» هدفًا لكل قطعة؛ اربطه بدورها.
- لا تضع تاريخ نشر قبل موعد إنتاج ومراجعة ممكن.
- أي قطعة بلا دليل أو مالك أو موعد مراجعة تذهب إلى المؤجل.

## عقد المخرجات

مبادئ الفترة، سجل أفكار، تقويم إنتاج ونشر، حمل عمل، إعادة استخدام مقصودة، مؤجل وموانع.

استخدم `assets/output-template.md` وراجع `examples/`.
