# منهج تحليل المرتجعات

المعدل = الوحدات المرتجعة بعد التسليم / الوحدات المسلمة في المجموعة نفسها. سجّل التأخر الزمني لأن بعض الطلبات الحديثة لم تدخل نافذة الإرجاع كاملة.

ابدأ من السبب الأكبر الذي يمكن للمتجر إصلاحه: وصف، صور، جدول مقاسات، ضبط جودة، تغليف، أو تجهيز. لا تخلط «تغيير رأي» مع عيب ولا تستخدم النص الخام للحكم على العميل.
