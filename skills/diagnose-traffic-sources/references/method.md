# منهج تشخيص القنوات

## ترتيب التحقق

1. الفترة والعملة والمنطقة ونموذج الإسناد.
2. هل المصدر ووسيط الحملة موحدان أم توجد مشكلة UTM أو قناة غير معروفة؟
3. الإجراء بعد الزيارة: عرض منتج، إضافة سلة، بدء دفع، طلب.
4. التكلفة والربح فقط إذا كانا من الفترة والنطاق نفسيهما.

## قرار القناة

- **أصلح:** يوجد عطل أو عدم تطابق مثبت بين الرسالة والصفحة أو القياس.
- **اختبر:** توجد فرضية معقولة لكن لا يكفي الدليل للجزم.
- **راقب:** توجد إشارة لكنها تحتاج فترة مقارنة أو بيانات أكمل.
- **لا تحكم:** المقام أو التكلفة أو الإسناد لا يسمح بحكم تجاري.

## تعريف النجاح

قرار واحد يمكن اختباره، لا ترتيب تسويقي من أرقام ناقصة.
