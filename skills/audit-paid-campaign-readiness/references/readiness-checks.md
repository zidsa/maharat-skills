# قائمة فحص جاهزية الإعلان

كل فحص له معرّف ثابت، ومجال، وهل هو حرج أو قاتل، ونطاقه (يُثبت من الصفحة العامة أو يحتاج فحصًا داخليًا)، وكيف يُفحص، ومتى ينجح. المقيّم `scripts/evaluate-campaign.mjs` يعرف القائمة نفسها بهذا الترتيب، ويرفض أي معرّف خارجها أو أي فحص ناقص منها. الترتيب هو أولوية الإصلاح داخل كل مجموعة.

| المعرّف | المجال | حرج؟ | النطاق | كيف يُفحص | ينجح عندما |
|---|---|---|---|---|---|
| `offer.defined` | العرض | قاتل | داخلي | يؤكده التاجر، ويُقرأ الكوبون من `Coupons` في ربط زد إن وُجد | العرض وشروطه ومدته بالسنة مكتوبة، والمتجر يستطيع الوفاء به طوال المدة |
| `offer.discount_licence` | العرض | إذا كان العرض خصمًا | داخلي | تحقق من اشتراط ترخيص التخفيضات لهذا العرض في خدمة وزارة التجارة، واطلب الترخيص من التاجر | يوجد ترخيص ساري يغطي المنتجات والمدة، أو يوثّق التاجر من مصدر رسمي مؤرخ أن العرض لا يحتاجه |
| `ad.policy_claims` | الإعلان والسياسة | قاتل | داخلي | قارن نص الإعلان والمنتج بسياسة المنصة المختارة | لا ادعاء صحي أو مضلل أو «الأرخص» بلا دليل، والمنتج غير محظور أو مقيد في المنصة |
| `ad.influencer_licence` | الإعلان والسياسة | قاتل إذا وُجد صانع محتوى | داخلي | تحقق من اشتراط ترخيص «موثوق» ومن رقم ترخيص صانع المحتوى وتاريخ انتهائه | الترخيص موجود وساري حتى نهاية الحملة |
| `landing.loads_right_page` | صفحة الهبوط | نعم | عام | افتح الرابط كما سيُوضع في الإعلان | يفتح صفحة المنتج أو المجموعة المعلن عنها مباشرة، لا الرئيسية ولا صفحة خطأ |
| `landing.message_match` | صفحة الهبوط | نعم | عام | قارن وعد الإعلان بأعلى الصفحة | المنتج والعرض ومدته ظاهرة بالكلمات والأرقام نفسها قبل السلة |
| `landing.price_matches` | صفحة الهبوط | نعم | عام | السعر في الإعلان والصفحة والسلة | السعر نفسه بالريال شامل الضريبة، والسعر قبل الخصم وبعده ظاهران إن وُجد خصم |
| `landing.cta_to_checkout` | صفحة الهبوط | نعم | عام | اضغط زر الشراء حتى صفحة الدفع دون إدخال بيانات دفع | المنتج متاح، والزر يضيفه ويفتح السلة ثم الدفع دون خطأ أو حلقة |
| `landing.mobile_rtl` | صفحة الهبوط | نعم | عام | اعرض الصفحة كجوال بالعربي، أو اطلب لقطات من التاجر | النص من اليمين، لا قص أفقي، الزر ظاهر دون تمرير طويل، والشروط قريبة منه |
| `stock.covers_campaign` | العرض | نعم | داخلي | `ProductStock` من ربط زد أو لوحة زد | المخزون المتاح لا يقل عن `budget.expected_orders` |
| `measurement.pixel_installed` | القياس | نعم | داخلي | تطبيق المنصة في زد (سناب شات، تيك توك، ميتا) أو ربط التسويق مثل Google Tag Manager | التطبيق مفعّل ومرتبط بحساب الإعلانات نفسه |
| `measurement.purchase_event_verified` | القياس | نعم | داخلي | طلب اختبار ثم أداة الأحداث في المنصة | حدث الشراء من طلب الاختبار ظهر بقيمته وعملته، ويذكر الدليل رقم الطلب |
| `measurement.zid_order_visible` | القياس | نعم | داخلي | طلبات زد وتقاريرها، أو `Orders` في ربط زد | طلب الاختبار نفسه ظاهر بقيمته، ويذكر الدليل رقمه |
| `budget.daily_cap_set` | الميزانية والإيقاف | نعم | داخلي | لقطة من إعداد الحملة أو مسودتها في المنصة | الحد اليومي مضبوط في حساب الإعلانات كما في الملف |
| `landing.policies_visible` | صفحة الهبوط | لا | عام | روابط الاسترجاع والشحن من صفحة الهبوط | سياسة الاسترجاع ومدة الشحن وتكلفته ظاهرة أو مرتبطة قرب زر الشراء |
| `ad.creative_specs` | الإعلان والسياسة | لا | داخلي | ملف الإعلان مقابل مواصفات المنصة | المقاس والمدة مناسبة، والنص العربي مقروء داخل المنطقة الآمنة |
| `ops.support_ready` | الميزانية والإيقاف | لا | داخلي | يؤكده التاجر | شخص يرد على العملاء في أوقات الإعلان |

- **قاتل:** فشله يعني «لا تشغّل» هذا الإعلان بصيغته. إن كانت حالته `not_tested` فهو مانع حرج يعني «أصلح أولًا».
- **حرج:** فشله أو عدم اختباره يعني «أصلح أولًا».
- **النطاق:** «عام» يُثبت من الصفحة العامة؛ «داخلي» يحتاج لوحة زد أو حساب الإعلانات أو طلب اختبار أو تأكيد التاجر.

## مخطط ملف الحملة

```json
{
  "campaign": {
    "store_url": "https://…",
    "landing_url": "https://…/products/…",
    "channel": "snapchat",
    "objective": "طلبات شراء",
    "creative_summary": "ماذا يقول الإعلان ويعرض",
    "offer": { "type": "discount", "summary": "خصم 15%: 199 قبل و169 بعد شاملة الضريبة", "ends_at": "2026-10-10T23:59:00+03:00" },
    "uses_influencer": true,
    "stock_units": 120,
    "starts_at": "2026-10-01T20:00:00+03:00"
  },
  "decision_at": "2026-09-28T11:00:00+03:00",
  "budget": { "daily_cap_sar": 300, "total_cap_sar": 2100, "margin_per_order_sar": 70, "expected_orders": 35 },
  "stop_rule": { "max_cpa_sar": 60, "spend_without_order_sar": 250, "owner": "صاحب المتجر", "action": "إيقاف المجموعة الإعلانية ثم المراجعة" },
  "test_order_id": "20931",
  "checks": [
    { "id": "measurement.zid_order_visible", "status": "passed", "evidence": { "source": "zid_dashboard", "detail": "طلب الاختبار 20931 ظاهر في طلبات زد بقيمة 169 ريالًا", "checked_at": "2026-09-28T10:30:00+03:00" } },
    { "id": "landing.policies_visible", "status": "failed", "note": "لا رابط للاسترجاع في الصفحة", "fix": { "summary": "إضافة رابط الاسترجاع تحت زر الشراء", "owner": "صاحب المتجر", "due_at": "2026-09-30T18:00:00+03:00" } }
  ],
  "decision": "fix_first"
}
```

- `campaign.channel`: واحدة من `snapchat`, `tiktok`, `meta` (إنستقرام وفيسبوك), `google`. لكل منصة ملف مستقل.
- `campaign.offer.type`: `discount`, `free_shipping`, `bundle`, `gift`, `none`. غير `none` يحتاج `summary` و`ends_at` بعد `starts_at`.
- `status`: `passed`, `failed`, `not_tested`, `not_applicable`. الأخيرة للفحصين المشروطين فقط عندما لا يتحقق شرطهما.
- `evidence` مطلوب مع `passed`: `source` من المصادر المقبولة لذلك الفحص في المقيّم، و`detail` محدد، و`checked_at` قبل القرار بحد أقصى 7 أيام. قراءات ربط زد تُسجّل بمصدر `zid_dashboard`.
- `measurement.purchase_event_verified` لا ينجح إلا بمصدر `test_purchase` أو `ads_platform`، و`measurement.zid_order_visible` إلا بمصدر `zid_dashboard`؛ وكلاهما يحتاج `test_order_id` مذكورًا في الدليل.
- `fix` مطلوب لكل فحص `failed` أو `not_tested`: `summary` و`owner`، ومعهما `due_at` بعد وقت القرار للفحص غير الحرج.
- `budget.daily_cap_sar` و`stop_rule` مطلوبان دائمًا. `stop_rule.max_cpa_sar` لا يتجاوز `budget.margin_per_order_sar`، و`stop_rule.spend_without_order_sar` لا يتجاوز الحد اليومي.
- `decision`: `run` (شغّل)، `fix_first` (أصلح أولًا)، `dont_run` (لا تشغّل)، ويجب أن تطابق ما يحسبه المقيّم.
- النصوص النموذجية مثل «…» مرفوضة؛ الملف غير المعبأ لا يمر.

ناتج المقيّم يحوي `computed_decision` و`reasons` و`fix_order` (ترتيب الإصلاحات: القاتل الفاشل، ثم الحرج الفاشل، ثم الحرج غير المختبر، ثم غير الحرج)، و`evidence_split` الذي يفصل ما ثبت من كل مصدر عن `needs_internal_testing` و`public_page_issues`.
