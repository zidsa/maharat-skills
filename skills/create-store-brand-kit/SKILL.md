# أنشئ هوية المتجر

حوّل اسم المتجر ومنتجاته إلى هوية على مرحلتين: اعرض ثلاثة خيارات مرتبطة بصورها أولًا، ولا تنشئ الأصول النهائية إلا بعد اختيار التاجر الصريح.

## ابدأ بالصور

1. اقرأ `references/input-contract.md`. اطلب فقط الاسم العربي كما يجب أن يظهر وما الذي يبيعه المتجر. إن غاب أحدهما، اسأل سؤالًا قصيرًا واحدًا عن المعلومة الناقصة.
2. عند اكتمال المدخلين، أنشئ الصور بقدرة إنشاء الصور الأصلية داخل المنصة الحالية. لا تستخدم تطبيقًا أو موصلًا أو موقعًا خارجيًا، ولا تطلب من التاجر إذن API أو CLI أو خدمة أخرى.
3. التصميمات نفسها مولدة بصريًا وليست مصممة بالكود أو SVG. يجوز استخدام تحرير الصور المدمج أو Python/Pillow أو أداة raster محلية بعد التوليد فقط لإزالة الخلفية والملاءمة والتصغير والتحسين والتصدير؛ لا يجوز أن تكون مصدر تصميم العلامة.

## حالة المحادثة وخريطة الخيارات

1. إذا لم يوجد `optionMap` حالي مكتمل، نفّذ المرحلة الأولى فقط. لا تختَر نيابة عن التاجر ولا تعتبر الإعجاب العام أو الملاحظة موافقة.
2. إذا كان `optionMap` يحتوي ثلاثة مراجع صور مستقلة وظاهرة ولم يختر التاجر أو يرفض، كرر سؤال الاختيار وحده وتوقف بلا توليد جديد.
3. إذا رفض الخيارات، امسح الخريطة القديمة وأعد المرحلة الأولى وفق ملاحظته بثلاث أفكار جديدة.
4. إذا اختار التاجر `N`، عيّن `selectedReference = optionMap[N]` فقط. لا تستخدم آخر صورة أو ترتيب مجموعة. اكتب `اعتمدت الخيار N.` وانتقل مباشرة إلى المرحلة الثانية بهذا المرجع بلا سؤال موافقة جديد.

## المرحلة الأولى: سطر ثم صورة، بالتتابع

أنشئ ثلاث معاينات صور مستقلة ومتتابعة بأي صيغة أو مقاس مرئي تدعمه المنصة. هذه معاينات اختيار فقط: لا تسمها ملفات، ولا تفرض عليها امتدادًا أو مقاسًا نهائيًا، ولا تشغّل عليها الفاحص.

لا تمرر تعليمات المهارة كاملة إلى إنشاء الصور. لكل بطاقة أدناه:

1. اكتب سطر الخيار كما هو خارج الصورة.
2. استدعِ إنشاء صورة واحدة بمحتوى `<single-image-prompt>` الخاص بها فقط.
3. انتظر حتى تظهر الصورة، ثم اربط رقمها فورًا بمرجع نتيجة الإنشاء نفسها في `optionMap` قبل الانتقال للبطاقة التالية.

بوابة الاختيار إلزامية: لا تسأل حتى تكون قيم `optionMap[1]` و`optionMap[2]` و`optionMap[3]` ثلاثة مراجع مختلفة لثلاث صور مستقلة وظاهرة، وبالترتيب المرئي المتناوب: `الخيار 1` ثم صورته، `الخيار 2` ثم صورته، `الخيار 3` ثم صورته. لا تستخدم `lastImage` أو ترتيب batch. إذا فشلت صورة، أعد بطاقة ذلك الخيار وحدها وحدّث مرجعها مع الاحتفاظ بالصورتين الناجحتين.

بعد اجتياز البوابة فقط، اكتب:

`اختر 1 أو 2 أو 3، أو قل: خيارات جديدة مع ملاحظتك.`

توقف وانتظر. لا تنشئ الشعار أو الأيقونة أو اللونين في رد المرحلة الأولى.

## المرحلة الثانية: الأصول النهائية بعد الاختيار

بعد اختيار صريح فقط:

1. اكتب `اعتمدت الخيار N.` وثبّت `selectedReference = optionMap[N]`. استخدم هذا المرجع نفسه فقط. تبقى لوحة الهوية المختارة مرجع الكتالوج الكامل كما ظهرت؛ لا تعِد تسميتها أو قصها أو تفرض عليها صيغة أو مقاسًا أو ملف تسليم.
2. أنشئ أصل الشعار بصريًا من جديد باستخدام `selectedReference` مرجعًا بصريًا مباشرًا. اطلب شفافية حقيقية والاسم العربي فقط. بعد نجاح التصميم، صدّره داخليًا إلى `logo-ar.png` 1024x256. إذا كان الأصل RGBA صحيحًا بمقاس مختلف، لاءم الأصل كاملًا مع الحفاظ على النسبة داخل لوحة شفافة بلا قص أو تشويه. إذا كان RGB أو معتمًا، أزل الخلفية فقط بتحرير الصور المدمج أو معالجة raster محلية مع حفظ التصميم؛ ويجوز توليده على خلفية مسطحة عالية التباين ثم إزالة الخلفية عند الحاجة.
3. أنشئ أصل الأيقونة بصريًا مرة واحدة من العلامة الفعلية داخل صورة `logo-ar.png` النهائية، مستخدمًا صورة الشعار نفسها مرجعًا بصريًا مباشرًا، بلا نص. لا تنشئها من الوصف النصي وحده. بعد نجاح هندستها، ثبّت أصل الأيقونة نفسه: إذا كانت المشكلة شفافية أو مقاسًا فقط، حرر أو عالج هذا الأصل نفسه ولا تعِد ابتكار رمز أو توليد هندسة جديدة. صدّره إلى `store-icon.png` 32x32 مع ملاءمة الأصل كاملًا داخل لوحة شفافة بلا قص أو تشويه.
4. اقرأ `references/production-method.md` وافحص الشعار والأيقونة النهائيين فقط. الخلفية الشطرنجية المرئية ليست شفافية وتفشل الفحص.
5. حافظ على هندسة العلامة وأسلوبها وألوانها بين الشعار والأيقونة، واستخرج `Primary` و`Secondary` من الهوية المعتمدة.

## عقد التسليم النهائي

أعد للتاجر بعد الاختيار هذا فقط، بالترتيب:

1. مرفق تنزيل فعلي: `logo-ar.png` 1024x256 بخلفية شفافة، الاسم العربي فقط.
2. مرفق تنزيل فعلي: `store-icon.png` 32x32 بخلفية شفافة، العلامة نفسها بلا نص.
3. `Primary: #RRGGBB`.
4. `Secondary: #RRGGBB`.

إذا فشل الفحص، أصلح تصدير الأصل نفسه داخليًا وأعد فحصه. لا تطلب من التاجر تشغيل أمر أو منح إذن أو استخدام API/CLI، ولا تنتقل إلى مولد صور أو خدمة خارجية. أسماء الملفات أو النص وحدها ليست مرفقات.

استخدم `assets/copy-paste-prompt.md` عند طلب نسخة جاهزة للصق، و`assets/output-template.md` لشكل الرد في كل مرحلة.

## تعريف النجاح

يرى التاجر ثلاثة خيارات مرتبة كسطر ثم صورة، ويشير كل رقم إلى مرجع الصورة الصحيح. بعد اختياره يحصل على شعار وأيقونة بهندسة ثابتة وشفافية حقيقية ومقاسين دقيقين، ثم لونين قابلين للنسخ.
