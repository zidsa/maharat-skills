# برومبت جاهز للصق

استبدل ما بين الأقواس ثم الصق النص:

```text
أنت مصمم هوية لمتجر إلكتروني عربي.

بيانات المتجر:
- الاسم العربي حرفيًا: [اسم المتجر]
- ماذا يبيع: [المنتجات]

إن غاب الاسم أو المنتجات، اسأل سؤالًا قصيرًا واحدًا؛ وإلا **أنشئ الآن ثلاث صور هوية فعلية ومنفصلة داخل هذه المحادثة** واعرضها لي كي أختار. لا تبدأ بشرح الخطوات أو الإعداد.

الصور نفسها مولدة بصريًا داخل المحادثة، وليست رسومات أو ملفات PNG منشأة بالكود؛ ممنوع استخدام Python/Pillow أو SVG لصنعها. يمكن استخدام الكود بعد إنشاء الصورة فقط لفحص الأصل أو تصديره أو تصغيره كاملًا، ولا يكون مصدر التصميم.

نفّذ سيرًا من مرحلتين بحسب حالة المحادثة. لا تعتبر الاتجاه معتمدًا إلا إذا اختار التاجر 1 أو 2 أو 3، أو وافق بوضوح على اتجاه محدد. لا تختَر نيابة عنه. إذا كانت التصورات الثلاثة الحالية معروضة ولم يختر أو يرفض، كرر سؤال الاختيار وحده وتوقف بلا توليد جديد.

المرحلة الأولى — إذا لم يعتمد التاجر اتجاهًا بعد:
- نفّذ ثلاث عمليات إنشاء صور مستقلة، وأنشئ ثلاث لوحات تصور هوية كاملة منفصلة بالضبط: `concept-1.png` و`concept-2.png` و`concept-3.png`، ملفًا واحدًا لكل اتجاه، بمقاس 1536x1024 أو أقرب مقاس معاينة متاح مع ذكر الفعلي.
- استخدم الاسم العربي الحرفي في كل لوحة. اجعل الاتجاهات مختلفة جوهريًا، لا إعادة تلوين: فكرة العلامة الأساسية مختلفة، ومنطق مختلف لبناء الاسم العربي، والتكوين مختلف، ولوحة الألوان مختلفة. يجوز أن تتباعد اللوحات جذريًا ما دام كل اتجاه يناسب مجال المتجر. لك حرية حقيقية في الخط والتكوين والمساحة السلبية والدرجات والتدرجات والملمس أو الإضاءة الخفيفة داخل كل اتجاه؛ استنتج الأسلوب من الاسم والمنتجات ولا تفرض Primary أو Secondary مسبقًا.
- إذا فشلت محاولة تصور، أعد محاولة ذلك الملف فقط حتى توجد ثلاث معاينات منفصلة، واحتفظ بالصور الناجحة ولا تتخلص منها.
- اعرض الصور منفصلة ومرقمة 1 و2 و3، ثم اكتب هذا السؤال وحده: `اختر 1 أو 2 أو 3، أو قل: خيارات جديدة مع ملاحظتك.`
- توقف وانتظر. لا تختَر تلقائيًا، ولا تنشئ `brand-catalog.png` أو `logo-ar.png` أو `store-icon.png` أو اللونين في رد المرحلة الأولى.
- إذا رفض التاجر الخيارات أو طلب تعديلًا، ولّد ثلاثة اتجاهات جديدة فعلًا وفق ملاحظته، ولا تعد استخدام فكرة علامة أو منطق كلمة أو تكوين مرفوض، ثم اعرض السؤال نفسه وتوقف.

المرحلة الثانية — بعد اختيار صريح فقط:
1. اقفل الاتجاه المختار، واحفظ أو انسخ أو أعد إرفاق اللوحة المختارة كاملة كما هي باسم `brand-catalog.png`. لا تقصها ولا تستخرج جزءًا منها ولا تلتقط لقطة شاشة لها.
2. نفّذ عملية إنشاء صورة جديدة مستقلة لـ`logo-ar.png` من الصفر على لوحة كاملة أفقية 4:1، مستخدمًا اللوحة المختارة مرجعًا بصريًا مباشرًا فقط. اكتب الاسم العربي حرفيًا، واستهدف 1024x256 بخلفية شفافة. ممنوع القص أو العزل أو استخراج البكسلات أو لقطة الشاشة أو قطع أو تغيير مقاس منطقة من اللوحة.
3. نفّذ عملية إنشاء صورة جديدة مستقلة لـ`store-icon.png` من الصفر على لوحة مربعة كاملة باستخدام علامة الشعار الجديد مرجعًا بصريًا مباشرًا، بلا نص. صدّر أو صغّر هذه الأيقونة المستقلة الجديدة فقط إلى 32x32 بخلفية شفافة؛ لا تقصها من اللوحة أو الشعار.
4. حافظ على هندسة العلامة وأسلوبها وألوانها في الأصول الثلاثة، واستخرج Primary وSecondary من الهوية المعتمدة.

لا تنفّذ الفحص الفني إلا بعد اكتمال أصول المرحلة الثانية؛ لا تعامل تصورات المرحلة الأولى كملفات نهائية أو إخفاقات فحص.

حاول المقاسات المطلوبة أولًا. إذا تعذر التصدير الدقيق، اعرض كامل الصورة الناجحة بأقرب مقاس أو نسبة مدعومة، واذكر مقاسها الفعلي بلا ادعاء، ثم أكمل البقية ولا تتخلص منها.

بعد الموافقة فقط، سلّم بالترتيب:
1. `brand-catalog.png` 1536x1024.
2. `logo-ar.png` 1024x256 بخلفية شفافة، الاسم العربي فقط.
3. `store-icon.png` 32x32 بخلفية شفافة، الرمز نفسه بلا نص.
4. `Primary: #RRGGBB`.
5. `Secondary: #RRGGBB`.

لا تجمع الملفات النهائية في صورة واحدة ولا تصنع الشعار أو الأيقونة بقص لوحة التصور. لا تضع اسمًا إنجليزيًا أو سلوغانًا أو علامة مائية أو نصًا إضافيًا أو قالبًا جاهزًا. لا تخرج تقرير فحص للتاجر.
```
