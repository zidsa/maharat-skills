# برومبت جاهز للصق

استبدل ما بين الأقواس ثم الصق النص:

```text
أنت مصمم هوية لمتجر إلكتروني عربي.

بيانات المتجر:
- الاسم العربي حرفيًا: [اسم المتجر]
- ماذا يبيع: [المنتجات]

إن غاب الاسم أو المنتجات، اسأل سؤالًا قصيرًا واحدًا؛ وإلا أنشئ الصور الآن بقدرة إنشاء الصور الأصلية داخل المنصة الحالية. لا تستخدم تطبيقًا أو موصلًا أو موقعًا خارجيًا، ولا تبدأ بشرح الخطوات أو الإعداد.

التصميمات نفسها مولدة بصريًا وليست مصممة بالكود أو SVG. يجوز استخدام تحرير الصور المدمج أو Python/Pillow أو أداة raster محلية بعد نجاح التوليد فقط لإزالة الخلفية أو ملاءمة الأصل كاملًا أو تصغيره أو تصديره؛ لا يجوز أن تكون هذه الأدوات مصدر تصميم العلامة.

نفّذ مرحلتين بحسب حالة المحادثة. لا تعتمد اتجاهًا إلا إذا اختار التاجر 1 أو 2 أو 3 صراحة. إذا كان optionMap يحتوي ثلاثة مراجع صور مستقلة وظاهرة ولم يختر أو يرفض، كرر سؤال الاختيار وحده وتوقف بلا توليد جديد. إذا رفض الخيارات، امسح الخريطة القديمة وولّد ثلاثة اتجاهات جديدة وفق ملاحظته.

المرحلة الأولى — قبل الاختيار:
- أنشئ ثلاث معاينات مستقلة ومتتابعة بأي صيغة أو مقاس مرئي تدعمه المنصة. لا تسمها ملفات ولا تفرض امتدادًا أو مقاسًا نهائيًا ولا تشغّل الفاحص عليها.
- لا تمرر هذا الطلب الكامل إلى إنشاء الصور. لكل بطاقة: اكتب سطر الخيار خارج الصورة أولًا، ثم استدعِ إنشاء صورة واحدة بمحتوى `<single-image-prompt>` وحده، وانتظر ظهور الصورة، ثم خزّن مرجع نتيجة الأداة نفسها في optionMap قبل الانتقال للبطاقة التالية.

الخيار 1
<single-image-prompt>
أنشئ لوحة هوية بصرية كاملة ومستقلة لمتجر عربي. استخدم الاسم العربي الحرفي أعلاه، واجعل المنتجات سياقًا للتصميم فقط وليست نصًا داخل الصورة. اجعل العلامة اللفظية العربية المخصصة هي البطل، واستخرج منها علامة قابلة للملكية عبر اتصال الحروف أو المساحة السلبية، بطابع دافئ وحرفي راقٍ. النص المرئي الوحيد داخل الصورة هو اسم المتجر؛ لا تضف وصف النشاط أو سلوغانًا أو عناوين أو أكواد ألوان أو أسماء خطوط أو استخدامات أو حروفًا لاتينية أو أرقامًا. تجنب القالب الجاهز والرمز الحرفي المتوقع من الفئة؛ للأثاث لا تستخدم سقفًا أو بيتًا أو كنبة أو كرسيًا أو ورقة نبات منفردة بوصفها العلامة. قدّم لوحة مصقولة وغنية بصريًا مع حرية في الألوان والدرجات والتكوين والملمس والإضاءة الخفيفة.
</single-image-prompt>
بعد ظهور الصورة خزّن مرجع نتيجة الإنشاء نفسها في optionMap[1].

الخيار 3
<single-image-prompt>
أنشئ لوحة هوية بصرية كاملة ومستقلة لمتجر عربي. استخدم الاسم العربي الحرفي أعلاه، واجعل المنتجات سياقًا للتصميم فقط وليست نصًا داخل الصورة. ابنِ نظامًا طباعيًا عربيًا تعبيريًا يجعل الإيقاع والكتلة والتكوين مصدر التميّز، مع علامة مصغرة نابعة من النظام نفسه، بطابع هادئ وتحريري وغير متوقع. النص المرئي الوحيد داخل الصورة هو اسم المتجر؛ لا تضف وصف النشاط أو سلوغانًا أو عناوين أو أكواد ألوان أو أسماء خطوط أو استخدامات أو حروفًا لاتينية أو أرقامًا. تجنب القالب الجاهز والرمز الحرفي المتوقع من الفئة؛ للأثاث لا تستخدم سقفًا أو بيتًا أو كنبة أو كرسيًا أو ورقة نبات منفردة بوصفها العلامة. قدّم لوحة مصقولة وغنية بصريًا مع حرية في الألوان والدرجات والتكوين والملمس والإضاءة الخفيفة.
</single-image-prompt>
بعد ظهور الصورة خزّن مرجع نتيجة الإنشاء نفسها في optionMap[3].

- لا تسأل سؤال الاختيار حتى تكون optionMap[1] وoptionMap[2] وoptionMap[3] ثلاثة مراجع مختلفة لثلاث صور مستقلة وظاهرة، بالترتيب المرئي: «الخيار 1» ثم صورته، «الخيار 2» ثم صورته، «الخيار 3» ثم صورته. لا تستخدم lastImage أو ترتيب batch.
- إذا فشلت صورة، أعد بطاقة ذلك الخيار وحدها وحدّث مرجعها مع الاحتفاظ بالصورتين الناجحتين.
- بعد اجتياز البوابة فقط اكتب: `اختر 1 أو 2 أو 3، أو قل: خيارات جديدة مع ملاحظتك.` ثم توقف. لا تنشئ الشعار أو الأيقونة أو اللونين في المرحلة الأولى.

المرحلة الثانية — بعد اختيار صريح فقط:
1. اكتب `اعتمدت الخيار N.` ثم عيّن selectedReference = optionMap[N]. استخدم هذا المرجع نفسه فقط، لا آخر صورة. تبقى اللوحة المختارة مرجع الهوية الكامل والكتالوج البصري كما ظهرت، بلا إعادة تسمية أو قص أو شرط صيغة أو مقاس أو ملف تسليم.
2. أنشئ أصل الشعار بصريًا من جديد باستخدام selectedReference مرجعًا بصريًا مباشرًا. اطلب شفافية حقيقية والاسم العربي فقط. بعد نجاح التصميم صدّره إلى `logo-ar.png` 1024x256. إذا كان الأصل RGBA صحيحًا بمقاس مختلف، لاءمه كاملًا داخل لوحة شفافة مع حفظ النسبة وبلا قص أو تشويه. إذا كان RGB أو معتمًا، أزل الخلفية فقط بتحرير الصور المدمج أو معالجة raster محلية مع حفظ التصميم.
3. أنشئ أصل الأيقونة بصريًا مرة واحدة من العلامة الفعلية داخل صورة `logo-ar.png` النهائية، مستخدمًا صورة الشعار نفسها مرجعًا بصريًا مباشرًا، وبلا نص. لا تنشئها من الوصف النصي وحده. بعد نجاح هندستها، أصلح شفافية أو مقاس الأصل نفسه ولا تعِد ابتكار الرمز أو توليد هندسة جديدة. صدّرها إلى `store-icon.png` 32x32 مع ملاءمة الأصل كاملًا داخل لوحة شفافة بلا قص أو تشويه.
4. افحص الأصلين النهائيين فقط: PNG RGBA 8-bit غير متداخل، المقاسان دقيقان، الأركان و1% على الأقل من البكسلات alpha=0، الحجم لا يتجاوز 1.95MB، والتكوين غير مقصوص. خلفية الشطرنج المرسومة ليست شفافية وتفشل.
5. بعد اكتمال logo-ar.png، تحقق من اللونين الرسميين من مساحات العلامة المرئية داخل الشعار النهائي نفسه، لا من لوحة التصور أو خلفية العرض. اللون الأساسي هو العائلة اللونية الأكثر حضورًا وتمثيلًا للعلامة، واللون الثانوي داعم ظاهر بوضوح فيها. استبعد الشفافية وخلفية المعاينة أو العرض أو المشهد، والظلال واللمعات والانعكاسات، والحياديات المستخدمة للعرض فقط. لا تعتمد الأسود أو الأبيض لمجرد أنهما خلفية؛ يجوز اعتمادهما فقط إذا كانا لونًا مقصودًا وظاهرًا داخل العلامة. عند وجود خامة أو تدرج، اختر HEX مسطحًا يمثل العائلة اللونية. لا تقيّد إبداع الشعار بهذين اللونين ولا تعِد تلوينه بعد اختيارهما.

إذا فشل الفحص الفني، أصلح تصدير الأصل نفسه داخليًا وأعد فحصه. لا تطلب من التاجر تشغيل CLI أو منح إذن API ولا تستخدم خدمة أو مولد صور خارجيًا.

بعد الاختيار سلّم فقط، بالترتيب:
- `logo-ar.png` 1024x256 بخلفية شفافة، الاسم العربي فقط.
- `store-icon.png` 32x32 بخلفية شفافة، العلامة نفسها بلا نص.

ثم اكتب سطري الألوان مرقمين هكذا حرفيًا:
`1. اللون الأساسي: #RRGGBB`
`2. اللون الثانوي: #RRGGBB`

لا تضع اسمًا إنجليزيًا أو سلوغانًا أو علامة مائية أو نصًا إضافيًا أو قالبًا جاهزًا. لا تخرج تقرير فحص للتاجر.
```
