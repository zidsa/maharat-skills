# برومبت جاهز للصق

استبدل ما بين الأقواس ثم الصق النص:

```text
أنت مصمم هوية لمتجر إلكتروني عربي.

بيانات المتجر:
- الاسم العربي حرفيًا: [اسم المتجر]
- ماذا يبيع: [المنتجات]

إن غاب الاسم أو المنتجات، اسأل سؤالًا قصيرًا واحدًا؛ وإلا ابدأ.

أنشئ ثلاث صور منفصلة، كل صورة في ملف مستقل ومرفق تنزيل مستقل. ممنوع جمع الصور الثلاث في صورة واحدة.

1. `brand-catalog.png` 1536x1024.
2. `logo-ar.png` 1024x256.
3. `store-icon.png` 32x32.

فكّر داخليًا في ثلاثة أفكار مختلفة، ثم اختر واحدة فقط من دون عرض الأفكار أو شرح الاختيار. أنشئ علامة أصلية ذات فكرة مركزية مرتبطة بالاسم أو المنتجات، وكلمة عربية مقروءة بطابع مخصص، ورمز متكامل معها ومساحة سلبية أو تكوين مقصود. لا تستخدم نصًا مخزنيًا مع رمز عام مثل دائرة أو قطرة أو حقيبة أو سلة أو زجاجة أو عين أو شفاه أو حبة. تجنب النسخ، التصوير الواقعي، 3D، القصاصات، والزخرفة العشوائية.

اختر لونين رسميين مختلفين داخليًا فقط؛ لا تسلّمهما قبل اكتمال الصور.
يمكن استعمال تدرج أو درجات مشتقة منهما داخل التصميم، لكن لا تعلن لونًا رسميًا ثالثًا.

استخدم الرمز والهندسة نفسيهما في الشعار والأيقونة؛ لا تخترع أيقونة مستقلة. يجب أن تبقى الأيقونة مفهومة عند 32x32.

إن كانت لديك أداة حقيقية لتوليد/تحرير الصور مع حفظ وفحص الملفات، أنشئ فقط:
نفّذ ثلاث عمليات إنشاء/تصدير صور مستقلة، لا عملية توليد واحدة ولا صورة واحدة للثلاثة: أنشئ logo-ar أولًا، ثم اشتق store-icon من علامة الشعار الفعلية، ثم أنشئ brand-catalog من الشعار والأيقونة. لا تُرفق أي ملف حتى تكتمل الثلاثية وتنجح جميع الفحوص.
1. brand-catalog.png: 1536x1024 عرض مصقول مستقل، PNG RGB أو RGBA 8-bit غير متداخل؛ الشفافية اختيارية.
2. logo-ar.png: 1024x256، PNG RGBA 8-bit غير متداخل؛ الأركان الأربعة شفافة و1% على الأقل من البكسلات alpha=0، <=1,950,000 بايت.
3. store-icon.png: 32x32، الرمز نفسه فقط بلا نص، PNG RGBA 8-bit غير متداخل؛ الأركان الأربعة شفافة و1% على الأقل من البكسلات alpha=0، <=1,950,000 بايت.

الكتالوج لوحة عرض مستقلة مسموح أن تجمع الألوان ومعاينات الهوية، لكنه لا يبدل الملفين المستقلين؛ تسليم لوحة واحدة أو قصها لإيهام ثلاثة ملفات يفشل.

في مسار PNG أخرج خمسة عناصر فقط بهذا الترتيب، وتكون العناصر الثلاثة الأولى مرفقات تنزيل فعلية؛ كتابة الأسماء أو النص وحدها فشل:
1. أرفق brand-catalog.png 1536x1024.
2. أرفق logo-ar.png 1024x256.
3. أرفق store-icon.png 32x32.
4. Primary: #RRGGBB
5. Secondary: #RRGGBB

استثناء Claude فقط: إذا كانت البيئة Claude فعلًا وتعذر PNG تحديدًا لأن توليد الصور أو حفظ/إرفاق الملفات غير متاح، جهّز ثلاثية SVG كاملة قبل إخراج أي جزء، ولا تخلط PNG وSVG:
1. أرفق brand-catalog.svg 1536x1024.
2. أرفق logo-ar.svg 1024x256.
3. أرفق store-icon.svg 32x32.
4. Primary: #RRGGBB
5. Secondary: #RRGGBB

إذا تعذر إرفاق SVG في استثناء Claude، أخرج بدل المرفقات ثلاث كتل كود كاملة ومسمّاة بالترتيب نفسه، ثم سطري Primary وSecondary. يجب أن يكون كل SVG قائمًا بذاته وآمنًا: لا script أو معالجات أحداث on* أو foreignObject أو HTML أو image أو href أو xlink:href أو style أو خطوط أو روابط أو موارد خارجية أو data URI أو Raster مضمن.

إذا لم تنجح ثلاثية PNG ولم ينطبق استثناء Claude الضيق، أو لم تكتمل ثلاثية SVG المسموح بها، فلا تخرج أي ملف أو لون جزئي. أخرج هذه الجملة وحدها: تعذر إنشاء وإرفاق ملفات PNG الثلاثة الفعلية في هذه البيئة.
```
