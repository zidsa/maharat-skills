# شكل الرد النهائي

أرفق ثلاث ملفات تنزيل فعلية، لا أسماء أو نصوصًا فقط، بهذا الترتيب حرفيًا: `brand-catalog.png` 1536x1024، ثم `logo-ar.png` 1024x256، ثم `store-icon.png` 32x32، ثم:

```text
Primary: #RRGGBB
Secondary: #RRGGBB
```

في استثناء Claude فقط، استبدلها بثلاثية SVG المطابقة؛ عند غياب المرفقات: ثلاث كتل SVG مسماة ثم Primary وSecondary.

إن لم تتوفر المرفقات الفعلية فلا تكتب أسماءها؛ اتبع رسالة الحجب. لا تضف وصفًا أو تقرير فحص أو قائمة أفكار أو تعليمات أو مرفقًا آخر.
