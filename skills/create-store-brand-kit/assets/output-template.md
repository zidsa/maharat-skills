# شكل الرد في المرحلتين

## الرد الأول: اختيار الاتجاه

اعرض أو أرفق ثلاث صور منفصلة فقط، مرقمة بهذا الترتيب:

1. `concept-1.png` — لوحة تصور هوية كاملة.
2. `concept-2.png` — لوحة تصور هوية كاملة.
3. `concept-3.png` — لوحة تصور هوية كاملة.

كل لوحة أعلاه صورة مولدة بصريًا داخل المحادثة بعملية إنشاء مستقلة، وليست PNG مرسومة بالكود أو SVG أو لقطة أو قصاصة.

ثم اكتب سؤالًا واحدًا وتوقف:

`اختر 1 أو 2 أو 3، أو قل: خيارات جديدة مع ملاحظتك.`

لا تعرض في هذا الرد كتالوج التسليم أو الشعار أو الأيقونة النهائية أو اللونين. عند رفض الخيارات، كرر الشكل نفسه بثلاث صور جديدة فعلًا.

## الرد النهائي: بعد الموافقة فقط

اعرض أو أرفق الأصول بهذا الترتيب: `brand-catalog.png` 1536x1024، ثم `logo-ar.png` 1024x256، ثم `store-icon.png` 32x32، ثم:

```text
Primary: #RRGGBB
Secondary: #RRGGBB
```

`brand-catalog.png` هو كامل اللوحة التي وافق عليها التاجر، لا قصاصة منها. الشعار والأيقونة صورتان جديدتان منشأتان بعمليتين مستقلتين، وليستا أجزاء مقصوصة أو معزولة أو مصورة من اللوحة ولا رسومات برمجية. إذا تعذر تصدير مقاس أحد الأصول بدقة، اعرض أو أرفق كامل الصورة المولدة بأقرب مقاس أو نسبة مدعومة، واذكر مقاسها الفعلي بدل ادعاء المقاس المطلوب. أكمل الأصول الأخرى ولا تضف تقرير فحص.
