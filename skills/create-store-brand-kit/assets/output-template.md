# شكل الرد النهائي

اعرض أو أرفق ثلاث صور مستقلة بهذا الترتيب: `brand-catalog.png` 1536x1024، ثم `logo-ar.png` 1024x256، ثم `store-icon.png` 32x32، ثم:

```text
Primary: #RRGGBB
Secondary: #RRGGBB
```

إذا تعذر تصدير مقاس أحد الأصول بدقة، اعرض أو أرفق الصورة المولدة بأقرب مقاس أو نسبة مدعومة، واذكر مقاسها الفعلي بدل ادعاء المقاس المطلوب. أكمل الأصول الأخرى ولا تضف تقرير فحص أو قائمة أفكار أو تعليمات أو مرفقًا آخر.
