# منهج الإنتاج

## بعد تثبيت الفكرة

لا تقرأ هذا المرجع قبل اختيار الفكرة الإبداعية. هذه مرحلة تصدير وفحص لاحقة: حافظ على الفكرة المختارة عند التصدير ولا تبدأ اتجاهًا إبداعيًا جديدًا بسبب مواصفات الملف. حافظ على الاسم العربي الدقيق وعلى العلامة نفسها بين الشعار والأيقونة. `Primary` و`Secondary` هما اللونان الرسميان فقط؛ درجاتهما وتدرجاتهما والحياديات مسموحة داخل الرسم.

## مسار PNG

استخدمه فقط عند وجود توليد أو تحرير صورة حقيقي مع حفظ وفحص. أنشئ logo ثم icon من علامته الفعلية ثم catalog منهما، كثلاث عمليات وملفات مستقلة، ومرر العلامة المعتمدة كمرجع مباشر للأيقونة. افحص:

- أنشئ `logo-ar` أولًا، واشتق `store-icon` من علامة الشعار الفعلية، ثم كوّن `brand-catalog` من الشعار والأيقونة المكتملين؛ تحقق من الثلاثية قبل الإرفاق.
- `brand-catalog.png`: 1536x1024، عرض مصقول، PNG RGB أو RGBA 8-bit غير متداخل؛ الشفافية اختيارية لكن يجب أن يحتوي RGBA على بكسلات مرئية، <=10,000,000 بايت.
- `logo-ar.png`: 1024x256، اسم عربي مطابق، RGBA 8-bit غير متداخل؛ الأركان الأربعة شفافة و1% على الأقل من البكسلات `alpha=0`، <=1,950,000 بايت.
- `store-icon.png`: 32x32، الرمز نفسه بلا كتابة، RGBA 8-bit غير متداخل؛ الأركان الأربعة شفافة و1% على الأقل من البكسلات `alpha=0`، <=1,950,000 بايت.
- الفاحص البنيوي الحالي يقبل للكتالوج PNG RGB أو RGBA 8-bit غير متداخل، وللشعار والأيقونة PNG RGBA 8-bit غير متداخل فقط؛ لا يقبل chunk `tRNS`، فأعد التصدير بهذه الصيغة عند اختلافها.
- يفحص الفاحص الأصول الثلاثة التي تُمرر له فقط، ولا يرفض ملفات غير مرتبطة في مجلد مشترك؛ لكنه يرفض آثار التسليم القديمة المعروفة: `brand-board.png` و`colors-hex.txt` و`brand-kit.json` و`brand-kit-report.md`.

## الفحص بعد التصدير

شغّل الفاحص بعد اكتمال الملفات، لا أثناء اختيار الفكرة:

```bash
node scripts/validate-brand-kit.mjs <primary-hex> <secondary-hex> <catalog-asset> <logo-asset> <icon-asset>
```

استخدم `--claude-fallback` فقط مع ثلاثية SVG في استثناء Claude المسموح.

## استثناء Claude: SVG

SVG متاح فقط عندما تكون بيئة التشغيل Claude ولا تستطيع إتمام تسليم PNG المطلوب لأن توليد الصور أو حفظ/إرفاق ملفات PNG غير متاح. أعد استخدام تعريف الرمز أو هندسته نفسها حرفيًا بين الشعار والأيقونة. لا يسمح هذا الاستثناء لبيئة أخرى بإصدار SVG؛ هو إقرار تشغيلي وليس تحققًا من الهوية.

- `brand-catalog.svg`: 1536x1024، و`logo-ar.svg`: 1024x256، و`store-icon.svg`: 32x32؛ ثلاثية آمنة متطابقة فقط.

لا تستخدم `script` أو معالجات `on*` أو `foreignObject` أو HTML أو `<image>` أو `href` أو fonts خارجية أو data URI أو Raster مضمن. يسمح فقط بـ `url(#local-id)` المحلي لطلاء gradient أو mask؛ ارفض أي `url()` خارجي أو مشفر أو غير fragment. لا تقل إن SVG هو PNG.

في ChatGPT وGemini وManus وكل بيئة ليست Claude، إن تعذر إتمام PNG لتوليد الصور أو الحفظ/الإرفاق، أخرج وحدها: `تعذر إنشاء وإرفاق ملفات PNG الثلاثة الفعلية في هذه البيئة.` لا تستخدم SVG أو برومبتات بديلة.

## التسليم

لا تعرض سوى الكتالوج ثم الشعار ثم الأيقونة ثم Primary وSecondary. التحقق داخلي ولا يظهر كتقرير.

الفاحص البنيوي يتحقق من الصيغة والمقاس والشفافية/السلامة فقط. أصالة الفكرة، صحة العربية، وتطابق هندسة الشعار والأيقونة تحتاج مراجعة بصرية داخلية؛ لا تقدّمها كتقرير موجّه للتاجر.
