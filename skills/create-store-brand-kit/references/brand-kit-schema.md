# عقد مراحل وأصول الهوية

لا تنشئ ملف JSON أو manifest. هذا المرجع يحدد حالة المحادثة والمخرجات فقط.

## المرحلة الأولى: معاينات الاختيار

- نفّذ ثلاث عمليات صورة مستقلة ومتتابعة. كل عملية تستقبل اتجاهًا واحدًا فقط.
- اكتب `الخيار N` قبل استدعاء صورته مباشرة، وانتظر ظهور النتيجة ثم خزّن مرجع نتيجة الأداة نفسها في `optionMap[N]`.
- المعاينات بأي صيغة أو مقاس مرئي تدعمه المنصة؛ لا أسماء ملفات ولا امتداد أو مقاس نهائي ولا فاحص.
- النص المرئي الوحيد داخل كل معاينة هو اسم المتجر العربي الحرفي. المنتجات سياق تصميمي فقط؛ لا وصف نشاط ولا سلوغان ولا عناوين أو أكواد ألوان أو أسماء خطوط أو استخدامات أو رقم اتجاه داخل الصورة.
- المناهج الثلاثة مختلفة فعليًا: علامة لفظية بمساحة سلبية، علامة مجردة قابلة للملكية، ونظام طباعي عربي تعبيري. تجنب الحل الحرفي المتوقع من الفئة.
- سؤال الاختيار محظور حتى تشير `optionMap[1..3]` إلى ثلاث صور مستقلة وظاهرة ومختلفة. اختيار N يستخدم `optionMap[N]` فقط، لا آخر صورة أو ترتيب batch.
- عند الرفض، استبدل الخريطة بثلاثة اتجاهات جديدة وفق ملاحظة التاجر.

## المرحلة الثانية: بعد اختيار صريح

تبقى لوحة الخيار المختار مرجع الهوية الكامل ولا تصبح ملف تسليم مطلوبًا.

| الأصل | عقد التسليم |
|---|---|
| الشعار | `logo-ar.png` 1024x256، PNG RGBA 8-bit غير متداخل، شفافية حقيقية، الاسم العربي فقط، <=1.95MB |
| الأيقونة | `store-icon.png` 32x32 بالشروط نفسها، العلامة نفسها بلا نص، <=1.95MB |
| الألوان | `1. اللون الأساسي` ثم `2. اللون الثانوي` بصيغة HEX بعد الأصلين |

- أنشئ الشعار بصريًا من المرجع المختار، ثم استخدم صورة الشعار النهائية نفسها مرجعًا بصريًا مباشرًا لإنشاء الأيقونة مرة واحدة.
- لا تنشئ الأيقونة من النص وحده. بعد نجاح هندستها، أصلح الشفافية والمقاس على أصل الأيقونة نفسه ولا تولّد رمزًا بديلًا.
- الأصل RGBA ذو المقاس المختلف يُلاءم كاملًا داخل لوحة شفافة بالمقاس المطلوب مع حفظ النسبة، بلا قص أو تشويه.
- الأصل RGB أو المعتم تُزال خلفيته فقط بتحرير الصور أو معالجة raster بعد التوليد. الخلفية الشطرنجية المرسومة ليست شفافية.
- أدوات raster مسموحة كمعالجة تصدير فقط، وليست مصدر تصميم. SVG ليس أصل تسليم أو بديل تصميمي.
- بعد اكتمال الشعار، استخرج اللونين من مساحات العلامة المرئية في `logo-ar.png` نفسه: الأساسي هو الأكثر حضورًا وتمثيلًا للعلامة، والثانوي داعم ظاهر بوضوح. استبعد خلفية المعاينة أو العرض أو المشهد، والشفافية والظلال واللمعات والانعكاسات والحياديات المستخدمة للعرض فقط. لا تعتمد الأسود أو الأبيض لمجرد أنهما خلفية؛ عند خامة أو تدرج اختر HEX مسطحًا ممثلًا للعائلة اللونية. لا تقيّد تصميم الشعار باللونين.
