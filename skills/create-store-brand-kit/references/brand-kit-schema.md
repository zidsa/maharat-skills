# عقد مراحل وأصول الهوية

لا تنشئ ملف JSON أو manifest. هذا المرجع يحدد حالة المحادثة والمخرجات فقط.

## المرحلة الأولى: لوحة اعتماد واحدة

- نفّذ عملية صورة واحدة للوحة هوية كاملة ومستقلة.
- المعاينة بأي صيغة أو مقاس مرئي تدعمه المنصة؛ لا اسم ملف ولا امتداد أو مقاس نهائي ولا فاحص.
- يظهر `merchantNameLiteral` مرة واحدة فقط في التكوين الرئيسي المواجه. التطبيقات الأخرى تعرض العلامة المصغرة وحدها بلا نص.
- المنتجات سياق بصري فقط؛ لا وصف نشاط ولا سلوغان ولا عناوين أو أكواد ألوان أو أسماء خطوط أو حروف لاتينية أو أرقام.
- لا مقارنة ولا بدائل ولا عناوين اختيار داخل الصورة.
- بعد ظهور الصورة، احفظ مرجعها في `latestBoardReference` واسأل سؤال الاعتماد الواحد ثم توقف.
- بعد أي نتيجة مرئية لا يوجد retry تلقائي. يسمح بمحاولة إضافية واحدة فقط لفشل تقني لم ينتج صورة.
- عند الملاحظة، أنشئ لوحة معدلة واحدة من أحدث لوحة والملاحظة، ثم استبدل `latestBoardReference` واسأل سؤال الاعتماد نفسه.

## الاعتماد

- افحص الموافقة قبل أي fallback يعيد البداية.
- عند الموافقة، عيّن `approvedBoardReference = latestBoardReference`، أو استعد أحدث لوحة مرئية من سجل المحادثة إذا فُقدت الحالة الخفية.
- لوحة الهوية المعتمدة مرجع بصري فقط، وليست ملف تسليم ولا تُقص لصنع الشعار أو الأيقونة.

## المرحلة النهائية

| الأصل | عقد التسليم |
|---|---|
| الشعار | `logo-ar.png` 1024x256، PNG RGBA 8-bit غير متداخل، شفافية حقيقية، الاسم العربي فقط، <=1.95MB |
| الأيقونة | `store-icon.png` 32x32 بالشروط نفسها، العلامة نفسها بلا نص، <=1.95MB |
| الألوان | `1. اللون الأساسي` ثم `2. اللون الثانوي` بصيغة HEX بعد الأصلين |

- أنشئ الشعار من الصفر باستخدام اللوحة المعتمدة مرجعًا بصريًا، لا بقصها.
- تحقق أن الاسم المرسوم يطابق `merchantNameLiteral` حرفًا حرفًا. لا تنشئ الأيقونة قبل `finalNameVerified = true`؛ أصلح الخطأ بتحرير نص الشعار نفسه مع حفظ العلامة والأسلوب والألوان.
- استخدم صورة الشعار النهائية نفسها مرجعًا بصريًا مباشرًا لإنشاء الأيقونة من علامته الفعلية. لا تنشئ الأيقونة من النص وحده ولا تبتكر رمزًا بديلًا.
- الأصل RGBA ذو المقاس المختلف يُلاءم كاملًا داخل لوحة شفافة مع حفظ النسبة، بلا قص أو تشويه.
- الأصل RGB أو المعتم تزال خلفيته فقط بعد التوليد. الخلفية الشطرنجية المرسومة ليست شفافية.
- أدوات raster معالجة تصدير فقط وليست مصدر تصميم. SVG ليس أصل تسليم أو بديل تصميمي.
- بعد اكتمال الشعار، استخرج اللونين من مساحات العلامة المرئية في `logo-ar.png` نفسه: الأساسي الأكثر حضورًا وتمثيلًا، والثانوي داعم ظاهر. استبعد خلفية العرض والشفافية والظلال واللمعات والانعكاسات وحياديات العرض. لا تعتمد الأسود أو الأبيض لمجرد أنهما خلفية. مثّل الخامة أو التدرج بـHEX مسطح، ولا تقيّد تصميم الشعار باللونين.
- إذا كانت عملية صورة واحدة فقط مسموحة في الرد، احتفظ بالحالة والأصول المكتملة في `pendingFinalAsset` وأكمل التالي عند متابعة التاجر من دون إعادة المعاينة.
