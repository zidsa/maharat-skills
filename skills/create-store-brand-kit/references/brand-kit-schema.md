# عقد أصول الهوية

لا تنشئ ملف JSON أو manifest. هذا المرجع يحدد ما يجب أن يتسلمه التاجر فقط.

| القدرة | الكتالوج | الشعار | الأيقونة | الألوان النصية |
|---|---|---|---|---|
| توليد/تحرير صورة مع حفظ وفحص | `brand-catalog.png` 1536x1024 truecolor 8-bit غير متداخل | `logo-ar.png` 1024x256 RGBA 8-bit غير متداخل؛ الأركان الأربعة شفافة و1% `alpha=0` | `store-icon.png` 32x32 بالشروط نفسها | Primary وSecondary HEX بعد الصور |
| Claude فقط عند تعذر PNG | `brand-catalog.svg` 1536x1024 | `logo-ar.svg` 1024x256 | `store-icon.svg` 32x32 | Primary وSecondary HEX بعد الصور |

- لا تخلط PNG وSVG في التسليم الواحد.
- يلزم ثلاثة ملفات مستقلة فعلًا؛ الكتالوج لوحة عرض تجمع المعاينات لكنه لا يبدل ملف الشعار أو ملف الأيقونة.
- يجب أن تكون هندسة الرمز في الأيقونة مشتقة من هندسة الرمز نفسها في الشعار.
- SVG قائم بذاته: لا scripts أو أحداث أو `foreignObject` أو HTML أو صور/خطوط/موارد أو روابط خارجية أو Raster مضمن، ولا يصح كبديل عام خارج استثناء Claude.
- في استثناء Claude، إن تعذر إنشاء المرفق، تمثل ثلاث كتل SVG مسمّاة الثلاثية ثم سطرا اللونين.
