# سجل المصادر

تاريخ التحقق: 2026-08-25.

- [Zid Docs: Upload Logo Image](https://docs.zid.sa/upload-logo-image-35820591e0) — وجود رفع شعار المتجر بحسب اللغة.
- [Zid Docs: Upload Icon Image](https://docs.zid.sa/upload-icon-image-35821465e0) — وجود رفع أيقونة المتجر.
- [OpenAI Help: Images in ChatGPT](https://help.openai.com/en/articles/11084440) — يوضح دعم توليد وتحرير الصور وطلب خلفية شفافة؛ يبقى فحص الملف الناتج ضروريًا.

## عقد هذه المهمة

- المعاينة عملية صورة واحدة للوحة هوية واحدة. يظهر الاسم العربي الحرفي مرة واحدة في التكوين الرئيسي، وتستخدم التطبيقات الأخرى العلامة بلا نص.
- لا يوجد عرض بدائل أو مقارنة. بعد الصورة يسأل المساعد سؤال اعتماد واحدًا ويتوقف.
- عند الملاحظة، تُنشأ لوحة معدلة واحدة من أحدث لوحة والملاحظة. لا retry بعد ظهور صورة؛ يسمح بمحاولة إضافية واحدة فقط لفشل تقني بلا صورة.
- عند الموافقة، يُستخدم أحدث مرجع لوحة مرئية وافق عليه التاجر. الموافقة تُفحص قبل fallback يعيد المعاينة.
- البرومبت الشامل متحكم فقط ولا يُرسل إلى أداة الصور. كل استدعاء يتلقى طلب أصل واحدًا فقط: `BOARD_ONLY` ثم `LOGO_ONLY` ثم `ICON_ONLY`؛ استدعاء واحد = أصل واحد = canvas/ملف واحد.
- الشعار يُنشأ بصريًا من الصفر من اللوحة المعتمدة عبر `LOGO_ONLY`، ثم تُنتظر نتيجته الفعلية وتُحفظ في `finalLogoReference` ويُتحقق الاسم حرفًا حرفًا قبل إنشاء الأيقونة.
- الأيقونة تُنشأ عبر `ICON_ONLY` مع صورة `finalLogoReference` الفعلية مرجعًا مباشرًا، لا من النص وحده ولا كرمز جديد. لا يظهر رد مرحلي ولا توقف اختياري بين استدعاء الشعار والأيقونة.
- ملفا PNG النهائيان فقط هما `logo-ar.png` 1024x256 و`store-icon.png` 32x32، مع alpha فعلي وحد 1,950,000 بايت لكل ملف، ثم `1. اللون الأساسي` و`2. اللون الثانوي` بصيغة HEX.
- اللونان يستخرجان بعد اكتمال الشعار ومن مساحات العلامة المرئية داخله، لا من خلفية عرض المعاينة أو الظلال واللمعات والانعكاسات.
- يمكن استخدام تحرير الصور أو raster محلي بعد التوليد فقط لإزالة الخلفية أو ملاءمة الأصل كاملًا أو تصغيره أو تصديره. لا يستخدم كأداة تصميم.
- لا يُفترض حد صورة واحدة في الرد. فقط إذا رفضت المنصة فعليًا الاستدعاء التالي، تُحفظ الحالة والأصول الناجحة ويُستكمل الأصل التالي من دون إعادة المعاينة.
- لا يطلب من التاجر API أو CLI ولا يستخدم تطبيقًا أو موصلًا أو مولد صور خارجيًا.

المقاسات والحد المحافظ عقد تسليم لهذه المهمة، لا ادعاء بأنها موثقة في صفحات Zid أعلاه.
