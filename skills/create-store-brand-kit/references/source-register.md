# سجل المصادر

تاريخ التحقق: 2026-08-25.

- [Zid Docs: Upload Logo Image](https://docs.zid.sa/upload-logo-image-35820591e0) — وجود رفع شعار المتجر بحسب اللغة.
- [Zid Docs: Upload Icon Image](https://docs.zid.sa/upload-icon-image-35821465e0) — وجود رفع أيقونة المتجر.
- [OpenAI Help: Images in ChatGPT](https://help.openai.com/en/articles/11084440) — يوضح دعم توليد وتحرير الصور وطلب خلفية شفافة؛ يبقى فحص الملف الناتج ضروريًا.

## عقد هذه المهمة

- المرحلة الأولى ثلاث عمليات صورة أحادية مستقلة ومتتابعة. يكتب `الخيار N` قبل صورته، ثم يربط نتيجة الأداة نفسها بـ`optionMap[N]` قبل الانتقال.
- معاينات الخيارات لا أسماء أو امتداد أو مقاس نهائي لها ولا تدخل الفاحص. النص المرئي الوحيد داخلها اسم المتجر العربي، والمنتجات سياق فقط.
- سؤال الاختيار محظور قبل وجود ثلاثة مراجع صور مستقلة وظاهرة ومختلفة. اختيار N يستخدم `optionMap[N]` حرفيًا، لا آخر صورة.
- بعد الاختيار، تبقى اللوحة المختارة مرجع الهوية الكامل. لا يلزم تسليمها كملف.
- الشعار يُنشأ بصريًا من المرجع، ثم الأيقونة مرة واحدة من العلامة الفعلية داخل صورة الشعار النهائية. لا تنشأ الأيقونة من النص وحده ولا يعاد ابتكار هندستها لمعالجة مشكلة تصدير.
- ملفا PNG النهائيان فقط هما `logo-ar.png` 1024x256 و`store-icon.png` 32x32، مع alpha فعلي وحد 1,950,000 بايت لكل ملف، ثم Primary وSecondary.
- يمكن استخدام تحرير الصور أو raster محلي بعد التوليد فقط لإزالة الخلفية أو ملاءمة الأصل كاملًا أو تصغيره أو تصديره. لا يستخدم كأداة تصميم.
- RGB أو خلفية شطرنجية مرسومة لا تعد شفافية. الفاحص يختبر الشعار والأيقونة فقط؛ التكوين غير المقصوص وتطابق الهندسة يحتاجان مراجعة بصرية داخلية.
- لا يطلب من التاجر API أو CLI ولا يستخدم تطبيقًا أو موصلًا أو مولد صور خارجيًا.

المقاسات والحد المحافظ عقد تسليم لهذه المهمة، لا ادعاء بأنها موثقة في صفحات Zid أعلاه.
