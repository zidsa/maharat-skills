# نتيجة مثال: سَدوة

> هذه ألوان مثال مخصص لموجز سَدوة. لا تعد استخدامها لمتجر آخر.

## الحالة

- الحالة: `prompts_only`
- جاهزة للرفع: لا
- لم تُنشأ ملفات جاهزة للرفع.
- الموجود فعلًا: لوحة مفحوصة، اتجاه موصى به، وبرومبتان للإنتاج.

## الاتجاه المختار

«خيط يبني معينًا»: خط مستمر يكوّن رمزًا معينيًا بسيطًا، وإلى جانبه اسم «سَدوة» بكتابة عربية واضحة. تم رفض رمز النخلة لعموميته، ورمز السجادة لأنه يحصر نطاق المنتجات.

## لوحة الألوان

| الدور | HEX | السبب |
|---|---|---|
| الرئيسي | `#5A2134` | لون عميق يحمل القطع المصورة والزر الرئيسي دون استخدام الأسود الممنوع. |
| نص الرئيسي | `#FFFFFF` | لنص واضح على السطح الرئيسي. |
| الثانوي | `#8C4517` | لون ترابي دافئ للخيط والتفاصيل مع بقاء تباينه واضحًا. |
| نص الثانوي | `#FFFFFF` | للنص القصير على السطح الثانوي. |
| الخلفية | `#FFFDF8` | سطح فاتح هادئ لصور النسيج. |
| نص الخلفية | `#1C1917` | للقراءة الطويلة. |

## التباين

- يحسب الفاحص الرئيسي/نصه، الثانوي/نصه، الخلفية/نصها، واللونين مع الخلفية.
- لا تعتمد النتيجة على التقريب.

## برومبت الشعار المولّد

أنشئ شعارًا عربيًا أفقيًا 4:1 لمتجر «سَدوة»، يبيع قطع نسيج يدوية معاصرة. استخدم الاسم العربي نفسه فقط، ورمزًا بسيطًا من خيط مستمر يكوّن معينًا. الألوان من اللوحة المعتمدة. خلفية شفافة حقيقية. بلا إنجليزية، بلا شعار فرعي، بلا mockup أو جدار أو منتج أو ظل أو علامة مائية أو نمط شطرنجي. المخرج المطلوب 1024×256 PNG، مع مراجعة الهمزات والنقاط والتشكيل في «سَدوة».

## برومبت الأيقونة

أنشئ أيقونة PNG مربعة لمتجر «سَدوة». استخدم رمز الخيط المعيني وحده، بخط واحد عريض ومساحة سلبية واضحة. لا تضع اسم المتجر أو أي نص. خلفية شفافة حقيقية، بلا ظل، بلا mockup، بلا حافة رفيعة تختفي عند التصغير. صممها لتبقى مفهومة عند 32×32 وصدّرها بهذا المقاس.

## نتيجة الفحص

ملف `brand-kit.json` لوضع `prompts_only` اجتاز فحص المخطط ولوحة الألوان ووجود برومبتات الإنتاج. لم يفحص ملفات صور لأنها لم تُنتج.
