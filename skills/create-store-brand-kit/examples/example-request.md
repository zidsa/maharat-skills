# مثال طلب

استخدم `$create-store-brand-kit` لمتجري.

- الاسم العربي: سَدوة
- ماذا يبيع: قطع نسيج يدوية وهدايا صغيرة.
- تفضيل اختياري: أبيها هادئة، وتجنب الأسود.

أنت في بيئة نصية لا تحفظ صورًا، لذلك استخدم `prompts_only` ولا تقل إن ملفات PNG جاهزة.
سلّم الألوان كنص، وبرومبتات مستقلة للشعار والأيقونة ولوحة الهوية. لا تجمعها في صورة واحدة.
