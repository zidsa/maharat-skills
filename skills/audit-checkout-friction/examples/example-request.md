# طلب مثال

طلبات الجوال نزلت هذا الأسبوع. عندي أحداث السلة وبداية الدفع والشحن والشراء، وأبغى تدقيق رابط المتجر على عرض 390 بكسل بدون تنفيذ دفع حقيقي.

قارن بالأسبوع السابق بنفس السوق، وتأكد أن حدث الشراء يطابق سجل الطلب قبل الحكم. صنّف كل نتيجة إلى عيب مثبت أو فرضية أو فجوة قياس، ولا تستخدم أي بيانات بطاقة.
