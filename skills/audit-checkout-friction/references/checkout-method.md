# منهج تشخيص الدفع

القمع يحدد **أين** يحدث الانخفاض، لكنه لا يثبت **لماذا**. السبب يحتاج تسجيل خطأ أو إعادة إنتاج أو بحث مستخدم.

افصل دائمًا:
- مشكلة واجهة مثبتة.
- فرق طبيعي بين الأجهزة/مصادر الزيارات.
- حدث قياس مفقود أو مكرر.

اختبر على نسخة بناء وسوق وجهاز معلنة، وسجل الأدلة دون بيانات دفع أو معلومات شخصية.
