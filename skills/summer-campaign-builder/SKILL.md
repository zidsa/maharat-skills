# مجهّز حملة الصيف

حوّل تقرير واجهة «حزمة الصيف» إلى حملة جاهزة للمراجعة. احترم اختيارات التاجر حرفيًا، ولا تعِد طرح سؤال حسمته الواجهة.

## ابدأ من تقرير الواجهة

اقرأ `references/input-checklist.md`.

- إذا وصل تقرير التشغيل من الواجهة، اعتمده كمصدر المدخلات الأساسي.
- لا تسأل عن الهدف أو العروض أو القنوات عندما تكون محددة في التقرير.
- اسأل سؤالًا واحدًا مجمّعًا فقط إذا غابت معلومة تمنع إنتاج قناة مختارة، مثل رابط الطلب في رسالة واتساب.
- لا تحوّل الحقول الفارغة إلى حقائق.

## افهم المتجر من رابطه

إذا احتوى التقرير على رابط متجر عام وكانت أداة التصفح متاحة:

1. افتح الرابط العام دون تسجيل دخول.
2. راجع الصفحة الرئيسية وصفحة المنتج أو العرض المرتبطة بالحملة.
3. استخرج الأدلة الظاهرة فقط: اسم العلامة، نبرة النص، الألوان، نوع المنتجات، وصياغة الدعوة للشراء.
4. دوّن ما تعذر التحقق منه ولا تدّع الوصول إلى تحليلات أو عملاء أو إعدادات خاصة.
5. لا تنفذ شراءً أو نموذجًا أو رسالة أو تغييرًا في المتجر.

إذا تعذر فتح الرابط، أكمل من تقرير الواجهة واذكر هذا القيد في سطر واحد.

## نفّذ الحزمة

1. لخّص المتجر والمنتج والهدف والعرض والجمهور في موجز قابل للمراجعة.
2. افصل بين بيانات التاجر، وما تحقق من الرابط العام، وأي افتراض.
3. اقرأ `references/channel-prompts.md`.
4. أنشئ فقط القنوات المختارة:
   - **تيكتوك:** أصل ثابت 1080×1920 أو برومبت إنتاج نهائي إذا لم تتوفر أداة صور.
   - **سناب:** أصل ثابت 1080×1920 يُفهم خلال ثانيتين أو برومبت إنتاج نهائي.
   - **إنستقرام:** أصل ثابت 1080×1350 أو برومبت إنتاج نهائي.
   - **واتساب:** رسالة نهائية قصيرة تحتوي العروض المختارة فقط.
5. إذا توفرت أداة إنشاء صور وطلب المستخدم التنفيذ، أنشئ أصلًا واحدًا لكل قناة مرئية مختارة. وإلا سلّم برومبتًا نهائيًا يحمل كل بيانات الحملة.
6. حافظ على هوية المتجر الظاهرة. عند غيابها استخدم هوية زد `#1F0433` و`#AE72FF` مع لمسات صيفية `#6BE3E3` و`#F9E683`.
7. أضف خطة قياس قصيرة: المؤشر، رابط أو وسم التتبع، نقطة المقارنة، وموعد المراجعة.
8. اكتب النتيجة وفق `assets/output-template.md`.
9. افحص الناتج:

```bash
node scripts/validate-output.mjs <مسار-النتيجة.md>
```

## قواعد لا تتغير

- لا تضف خصمًا أو مدة أو سعرًا أو كاش باك أو قناة لم يخترها التاجر.
- لا تعد بنتيجة مضمونة ولا تصنع تقييمًا أو استعجالًا زائفًا.
- لا تستخدم أصلًا لا يملك التاجر حق استخدامه.
- لا تنشر أو ترسل أو تعدّل المتجر دون معاينة وموافقة صريحة.
- اجعل كل مخرج النهائي قابلًا للنسخ أو التوليد، لا نصيحة عامة.

## ترتيب التسليم

1. موجز الحملة ومصادر الفهم.
2. القنوات المختارة فقط.
3. المخرج النهائي لكل قناة.
4. خطة القياس.
5. قائمة مراجعة قبل النشر.
