# باني حملة الصيف

حوّل اختيارات التاجر إلى حزمة صيف جاهزة للمراجعة. أنتج فقط القنوات التي اختارها، ولا تضف قناة أو عرضًا من عندك.

## ابدأ من تقرير التشغيل

إذا أرسل المستخدم تقريرًا من صفحة «حزمة الصيف»، اعتمده كمصدر المدخلات الأساسي ثم تحقّق من اكتماله.

إذا لم يرسل تقريرًا، اجمع هذه المدخلات في سؤال واحد مختصر:

- اسم المتجر والسوق المستهدف.
- المنتج أو الكولكشن الذي تقوده الحملة.
- الهدف: استحواذ، إعادة استهداف، أو كلاهما.
- العروض الفعلية فقط: خصم، توصيل مجاني، كاش باك، أو كولكشن مجمّع.
- مدة الحملة ورابط الطلب.
- القنوات المطلوبة: تيكتوك، سناب، إنستقرام، واتساب.

اقرأ `references/input-checklist.md` للتأكد من المدخلات. إذا اختار المستخدم واتساب فقط، أنشئ رسالة واتساب فقط مع موجز الحملة والقياس، ولا تنشئ برومبتات إعلانات.

## نفّذ الحزمة

1. لخّص الهدف والجمهور والعرض في سطر واضح.
2. افصل الحقائق التي قدّمها المستخدم عن أي افتراض.
3. اقرأ `references/channel-prompts.md`.
4. أنشئ مخرجًا لكل قناة مختارة فقط:
   - تيكتوك: صورة ثابتة 1080×1920.
   - سناب: صورة ثابتة 1080×1920 تُفهم خلال ثانيتين.
   - إنستقرام: صورة ثابتة 1080×1350.
   - واتساب: رسالة قصيرة بفقرات العرض المتاحة فقط.
5. اجعل المنتج والعرض واضحين من النظرة الأولى، والنص العربي قليلًا وقابلًا للقراءة.
6. استخدم هوية زد: `#1F0433` و`#AE72FF` مع لمسات صيفية `#6BE3E3` و`#F9E683`.
7. أضف خطة قياس قصيرة مرتبطة بالهدف، مثل النقرات أو التحويلات أو استعادة السلات.
8. اكتب النتيجة وفق `assets/output-template.md`.
9. افحص الناتج قبل التسليم:

```bash
node scripts/validate-output.mjs <مسار-النتيجة.md>
```

## قواعد المحتوى

- لا تختلق خصمًا أو مدة أو رابطًا أو سعرًا.
- لا تذكر عرضًا غير مختار.
- لا تعد بنتيجة مضمونة.
- لا تستخدم صور أشخاص أو شعارات أو منتجات لا يملك المستخدم حق استخدامها.
- لا تنشر أو ترسل الحملة دون موافقة صريحة؛ سلّمها كمسودة جاهزة للمراجعة.
- اكتب «غير متاح» عند غياب معلومة لا يمكن استنتاجها بأمان.

## التسليم

قدّم بالترتيب:

1. موجز الحملة.
2. القنوات المختارة.
3. المخرجات الجاهزة لكل قناة مختارة.
4. خطة القياس.
5. قائمة مراجعة قبل النشر.
