# عقد التشغيل

## المهمة

حوّل manifest حملة الصيف ومدخلات التاجر إلى مخرجات القنوات المختارة فقط، مع أدلة وخطة قياس وفحص قبل النشر.

## التسلسل الإلزامي

1. اقرأ `../SKILL.md` كاملًا.
2. اقرأ `../references/input-checklist.md` وحدد اكتمال المدخلات.
3. اقرأ `../references/source-register.md` و`../references/channel-prompts.md` قبل ذكر مواصفات المنصات.
4. راجع الرابط العام إن أمكن دون تسجيل دخول.
5. اكتب النتيجة وفق `../assets/output-template.md` واحذف القنوات غير المختارة.
6. طبّق `../references/safety-checklist.md`.
7. افحص الناتج مع طلب التشغيل قبل التسليم.

## عقد النتيجة

- كل حقيقة موسومة بمصدرها.
- كل قناة وعرض غير مختارين غائبان عن قسم المخرجات.
- كل نص نهائي منفصل عن ملاحظات التنفيذ.
- النتيجة مسودة قابلة للمراجعة؛ لا يوجد نشر أو إرسال تلقائي.
