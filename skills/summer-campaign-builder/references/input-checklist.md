# عقد متغيرات حملة الصيف

## manifest المعتمد

استخدم المخطط `summer-campaign-v1` عند وجوده:

```json
{
  "schema_version": "summer-campaign-v1",
  "campaign": {
    "store_name": "",
    "market": "",
    "store_url": "",
    "product_or_collection": "",
    "duration": "",
    "order_url": ""
  },
  "goals": [],
  "offers": [{ "type": "", "value": "", "scope": "" }],
  "channels": []
}
```

## مفاتيح الأهداف

- `acquire`: استحواذ عملاء جدد.
- `retarget`: إعادة استهداف الزوار أو غير المكملين.

يمكن اختيار أحدهما أو كليهما. لا يوجد هدف ثالث في عقد هذه المهارة.

## مفاتيح العروض

- `discount`: خصم؛ يتطلب نسبة ونطاقًا.
- `shipping`: توصيل مجاني؛ يتطلب مدة أو شرطًا.
- `cashback`: كاش باك؛ يتطلب قيمة وشروط استخدام.
- `bundle`: كولكشن مجمع؛ يتطلب اسمًا أو وصفًا.

## مفاتيح القنوات

- `tiktok`: تيكتوك.
- `snap`: سناب.
- `instagram`: إنستقرام.
- `whatsapp`: واتساب.

## بوابة الاكتمال

قبل الإنتاج، تأكد من:

- وجود اسم متجر، منتج أو كولكشن، مدة، ورابط وجهة صالح.
- وجود هدف واحد وعرض واحد وقناة واحدة على الأقل.
- وجود قيمة لكل عرض مختار.
- تطابق السوق واللغة والعملة مع صفحة الطلب.

إذا غاب أي عنصر مانع، اسأل سؤالًا واحدًا يجمع العناصر الناقصة ولا تنتج مخرجات جزئية توحي بالجاهزية.

## العلاقة مع أداة موسم الصيف الأصلية

تعكس هذه المفاتيح خيارات أداة `zid-summer.pages.dev` كما هي: هدفا الاستحواذ وإعادة الاستهداف، وأربعة عروض هي الخصم والتوصيل المجاني والكاش باك والكولكشن، وأربع قنوات هي تيكتوك وسناب وإنستقرام وواتساب. لا توسع المهارة هذه القوائم ولا تختار شيئًا نيابة عن التاجر.
