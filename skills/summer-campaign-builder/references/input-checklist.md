# قائمة مدخلات حملة الصيف

## مطلوبة

- اسم المتجر.
- المنتج أو الكولكشن.
- الهدف التسويقي.
- قناة واحدة على الأقل.
- العرض الفعلي أو توضيح عدم وجود عرض.
- مدة الحملة.

## مطلوبة عند الحاجة

- نسبة الخصم والمنتجات المشمولة.
- مدة التوصيل المجاني.
- قيمة الكاش باك وشروطه.
- اسم الكولكشن.
- رابط الطلب.
- السوق والجمهور.

## صيغة تقرير التشغيل المقبولة

```text
اسم المتجر:
السوق:
المنتج أو الكولكشن:
الهدف:
العروض:
المدة:
رابط الطلب:
القنوات:
ملاحظات:
```

لا تحوّل الحقول الفارغة إلى حقائق. اكتب «غير متاح» أو اطلب المعلومة إذا كانت تمنع تنفيذ القناة المختارة.
