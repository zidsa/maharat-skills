# قائمة مدخلات حملة الصيف

## من تقرير الواجهة

- اسم المتجر.
- رابط المتجر العام.
- السوق المستهدف.
- المنتج أو الكولكشن.
- الهدف التسويقي.
- العروض المختارة وقيمها.
- مدة الحملة.
- رابط الطلب أو صفحة العرض.
- قناة واحدة على الأقل.

## قاعدة القرار

- إذا كانت الحقول أعلاه مكتملة، ابدأ التنفيذ مباشرة ولا تعِد الأسئلة.
- إذا نقص حقل غير حاسم، استخدم «غير متاح» وواصل.
- إذا نقص رابط الطلب وكانت واتساب مختارة، اطلب الرابط في سؤال واحد قبل تسليم الرسالة النهائية.
- إذا اختيرت واتساب وحدها، لا تنشئ برومبتات إعلانات.
- إذا لم يُختر عرض سعري، أبرز قيمة المنتج ولا تخترع خصمًا.

## صيغة تقرير التشغيل

```text
اسم المتجر:
رابط المتجر العام:
السوق:
المنتج أو الكولكشن:
الهدف:
العروض:
مدة الحملة:
رابط الطلب:
القنوات المختارة فقط:
```

## فحص الرابط العام

- افتح صفحات عامة فقط.
- لا تسجل الدخول ولا تستخدم حسابًا أو بيانات دفع.
- دوّن URL والصفحة التي استندت إليها.
- افصل الهوية الظاهرة عن أي استنتاج.
