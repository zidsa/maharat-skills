# سلامة حملة الصيف

## قبل الكتابة

- [ ] المدخلات تخص المتجر الصحيح.
- [ ] رابط الوجهة يعمل على الجوال ويعرض المنتج والعرض نفسيهما.
- [ ] قيم العرض ومدته وشروطه موثقة.
- [ ] حقوق الصور والشعارات والخطوط معروفة.
- [ ] القنوات المختارة محددة في manifest.

## داخل المخرجات

- [ ] لا توجد أسعار أو خصومات أو هدايا أو ندرة غير مدخلة.
- [ ] لا توجد تقييمات أو شهادات أو أرقام مبيعات مصطنعة.
- [ ] لا يوجد زر أو إيماءة توحي بوظيفة غير موجودة.
- [ ] اللغة والعملة والسوق متسقة.
- [ ] الفئات المنظمة راجعت سياسة المنصة والسوق قبل الإنتاج.

## قبل أي إجراء خارجي

- [ ] النتيجة موسومة كمسودة.
- [ ] لم يتم النشر أو الإرسال أو تعديل المتجر.
- [ ] وافق مسؤول الحملة على النص والعرض والروابط.
- [ ] رسائل واتساب تذهب فقط إلى من وافقوا على الفئة التسويقية، مع احترام إيقاف الرسائل.
- [ ] تم اختبار القياس دون جمع بيانات شخصية غير لازمة.
