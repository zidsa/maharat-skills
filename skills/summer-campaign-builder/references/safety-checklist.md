# مراجعة السلامة قبل التسليم

- العرض والنسبة والمدة من بيانات المستخدم وليست افتراضًا.
- السعر والشروط متسقان مع صفحة الطلب.
- لا توجد وعود مضمونة أو ادعاءات غير موثقة.
- لا توجد قناة لم يخترها المستخدم.
- رسالة واتساب لا تحتوي فقرة لعرض غير مختار.
- الصور والشعارات والمنتجات المقترحة يملك المستخدم حق استخدامها.
- رابط الطلب موجود أو معلّم بوضوح كحقل ناقص.
- المخرجات معلمة كمسودة تحتاج مراجعة بشرية قبل النشر.
