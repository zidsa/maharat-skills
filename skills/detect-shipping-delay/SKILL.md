# كاشف تأخير الشحن

هذه المهارة تشخص خطر التأخر؛ لا تختار ناقلًا ولا تنفذ تعويضًا.

## سير العمل

1. اقرأ `references/delay-method.md` و`references/source-register.md`.
2. ثبّت المنطقة الزمنية ووقت القطع ومصدر الوعد لكل شحنة.
3. افصل: لا يوجد وعد، ضمن الوعد، خطر تأخر، تجاوز الوعد، أو تعارض بيانات.
4. استخدم آخر حركة وتوقيتها والمرحلة الحالية، ولا تساوِ «لا حركة» بـ«ضياع».
5. لكل شحنة مهددة اكتب الدليل والزمن المتبقي وإجراء الناقل وقرار التواصل والمالك والموعد.
6. استخدم قالب `assets/output-template.md` ثم شغّل `node scripts/validate-output.mjs <output.md> <shipments.json>`.

## الحد الأدنى من المدخلات

- معرف الطلب والشحنة دون بيانات عميل.
- الناقل وطريقة الشحن.
- وقت القطع والمنطقة الزمنية.
- آخر حركة شحن ووقتها.
- موعد التسليم الموعود ومصدره، أو SLA معتمد ونطاق تطبيقه.
- سياسة التواصل والتعويض المعتمدة ومالك التصعيد.

## حدود القرار

- لا تخترع SLA، ولا تنسب التأخر للناقل بلا دليل.
- لا تكتب «ضائعة» قبل تأكيد الناقل أو معيار المتجر.
- لا تعد بتاريخ أو تعويض جديد.
- إذا غاب الوعد وSLA، صنفها `غير قابلة للحكم` واطلب المرجع.

## عقد المخرجات

مصفوفة شحنات، سبب التصنيف، دليل زمني، إجراء الناقل، مسودة تواصل عند الحاجة، وحالات غير قابلة للحكم.

راجع أمثلة `examples/` قبل التسليم.
