# قائمة فحص الجاهزية

كل فحص له معرّف ثابت، ومجال، وهل هو حرج، وكيف يُفحص، ومتى يُعد ناجحًا. المقيّم في `scripts/evaluate-readiness.mjs` يعرف هذه القائمة نفسها ويرفض أي معرّف خارجها أو أي فحص ناقص منها.

| المعرّف | المجال | حرج؟ | كيف يُفحص | ينجح عندما |
|---|---|---|---|---|
| `products.catalog_ready` | المنتجات | نعم | صفحات المنتجات العامة أو قراءة المنتجات من ربط زد | لكل منتج معروض اسم وسعر بالريال وصورة واحدة على الأقل ووصف، ولا يوجد منتج بسعر صفر بالخطأ |
| `products.stock_set` | المنتجات | نعم | المخزون في لوحة زد أو من ربط زد | لا يظهر منتج «متوفر» وليس عنده مخزون، والمنتجات النافدة مخفية أو معلّمة |
| `products.options_complete` | المنتجات | لا | صفحات المنتجات ذات الخيارات | المقاسات والألوان والخيارات مكتملة ولكل خيار سعره ومخزونه |
| `payment.methods_active` | الدفع | نعم | صفحة الدفع أثناء الطلب التجريبي | طريقة دفع واحدة على الأقل مفعلة وتظهر للعميل وتعمل |
| `payment.test_order_paid` | الدفع | نعم | طلب تجريبي حقيقي على المتجر نفسه | الطلب دُفع وظهر في لوحة زد بحالة صحيحة، ثم أُلغي أو استُرد |
| `shipping.method_active` | الشحن | نعم | خيارات الشحن في الطلب التجريبي | طريقة شحن مفعلة تغطي المدن المستهدفة بسعر ومدة واضحين للعميل |
| `shipping.fulfilment_tried` | الشحن | لا | تجهيز الطلب التجريبي أو بوليصة تجريبية | خطوة التجهيز أو إنشاء البوليصة نُفذت ولو لمرة واحدة |
| `policies.returns_published` | السياسات والثقة | نعم | صفحة سياسة الاسترجاع العامة | منشورة وتوضح المدة والشروط والاستثناءات وطريقة الطلب |
| `policies.shipping_published` | السياسات والثقة | نعم | صفحة سياسة الشحن العامة | منشورة وتوضح المدة والتكلفة والمناطق |
| `policies.contact_working` | السياسات والثقة | نعم | صفحة التواصل، مع رسالة تجريبية | وسيلة تواصل ظاهرة (هاتف أو واتساب أو بريد)، وجُرّبت ووصل الرد |
| `policies.business_identity` | السياسات والثقة | نعم | تذييل المتجر أو صفحة «من نحن» | اسم الكيان وبيانات السجل التجاري أو وثيقة العمل الحر ظاهرة للعميل |
| `policies.vat_display` | السياسات والثقة | إذا كان المتجر مسجلًا في الضريبة | صفحة المنتج والفاتورة | الأسعار المعروضة شاملة الضريبة، والرقم الضريبي يظهر في الفاتورة |
| `policies.privacy_published` | السياسات والثقة | لا | صفحة الخصوصية العامة | منشورة وتوضح البيانات التي تُجمع وسبب جمعها |
| `storefront.mobile_checkout` | تجربة العميل | نعم | إكمال الطلب التجريبي من جوال بالعربي | يكتمل الطلب من الجوال دون نص مقطوع أو زر لا يعمل أو اتجاه خاطئ |
| `storefront.navigation_works` | تجربة العميل | لا | القوائم والأقسام والبحث من الجوال | الروابط الرئيسية والأقسام والبحث تعمل ولا توجد صفحة فارغة |
| `measurement.orders_visible` | القياس | نعم | تقارير الطلبات في لوحة زد | الطلب التجريبي يظهر في التقارير بقيمته الصحيحة |
| `measurement.ads_pixel` | القياس | إذا وُجدت حملة مدفوعة | أداة البكسل أو تطبيقها في زد | بكسل منصة الإعلان مركّب ويسجل الشراء من الطلب التجريبي |

«حرج» يعني أن فشله أو عدم اختباره يؤجل الافتتاح. الفحصان المشروطان يصبحان حرجين عند تحقق الشرط؛ وإلا فحالتهما `not_applicable`.

## مخطط ملف الجاهزية

```json
{
  "store": { "url": "https://…", "name": "…" },
  "decision_at": "2026-09-28T10:00:00+03:00",
  "launch_at": "2026-10-01T18:00:00+03:00",
  "vat_registered": true,
  "paid_campaign_at_launch": false,
  "checks": [
    {
      "id": "payment.test_order_paid",
      "status": "passed",
      "evidence": { "source": "test_order", "detail": "طلب #10452 دُفع بمدى وظهر مدفوعًا ثم استُرد", "checked_at": "2026-09-27T20:15:00+03:00" }
    },
    {
      "id": "products.options_complete",
      "status": "failed",
      "note": "ثلاثة منتجات بلا مقاس XL",
      "fix": { "summary": "إضافة مقاس XL ومخزونه", "owner": "سارة", "due_at": "2026-10-05T18:00:00+03:00" }
    }
  ],
  "decision": "conditional_launch",
  "rollback_plan": { "trigger": "فشل دفعين متتاليين", "owner": "صاحب المتجر", "action": "إخفاء المنتجات وإيقاف الحملة ثم مراجعة بوابة الدفع" }
}
```

- `status`: واحدة من `passed`, `failed`, `not_tested`, `not_applicable`.
- `evidence` مطلوب مع `passed`. قيم `source`: `zid_mcp`, `public_url`, `zid_dashboard`, `test_order`, `merchant`. ويكون `checked_at` قبل وقت القرار وبحد أقصى 14 يومًا.
- `payment.test_order_paid` لا ينجح إلا بمصدر `test_order`.
- `fix` مطلوب لكل فحص غير حرج حالته `failed` أو `not_tested`: `summary` و`owner` و`due_at` بعد وقت القرار.
- `not_applicable` مسموح فقط للفحصين المشروطين عندما لا يتحقق شرطهما.
- `decision`: واحدة من `launch`, `conditional_launch`, `postpone`، ويجب أن تطابق ما يحسبه المقيّم.
- `rollback_plan` مطلوب مع `launch` و`conditional_launch`، ويحوي `trigger` و`owner` و`action`.
