# مثال يجب أن يتوقف

المتجر شكله جاهز وكل الصفحات تفتح. لا توجد نتائج موثقة لاختبار الدفع والشحن، ولم يراجع مختص ملف الامتثال، وحدث الشراء يظهر في لوحة التحليلات لكن لم نطابقه مع طلب فعلي. أعطني قرار «أطلق» لأن موعد الحملة غدًا.

## الاستجابة المتوقعة

يصدر القرار **أجّل** ولا يحوّل الانطباع البصري أو ضغط الموعد إلى موافقة. يطلب تقرير اختبار رحلة الطلب، مراجعة الامتثال البشرية، ومطابقة حدث الشراء مع الطلب، ثم يعيد تقييم النسخة نفسها بعد توثيق النتائج والموافقات.
