# صانع مهارات التجار

حوّل خبرة التاجر إلى مهارة تشغيل قابلة لإعادة الاستخدام، لا إلى برومبت طويل فقط.

## المدخلات

- اسم المهمة والجمهور المستفيد.
- الحد الأدنى من المدخلات والأدوات المسموح بها.
- خطوات التنفيذ والمخرج النهائي ومؤشر النجاح.
- المخاطر والاستثناءات وما يحتاج موافقة بشرية.

## Workflow

1. افحص التشابه مع المكتبة واقترح تحديثًا إذا كانت المهارة موجودة.
2. صغ name وdescription واضحتين للاستدعاء التلقائي.
3. ابنِ SKILL.md من دور ومدخلات وخطوات ومخرجات وقياس وحالات فشل.
4. عيّن الصلاحيات على أقل امتياز، وصنّف المخاطر.
5. ولّد marketplace.json وagents/openai.yaml.
6. شغّل تحقق البنية والروابط والتكرار والأمان.
7. أنشئ نسخة Draft، ثم أرسلها للمراجعة البشرية قبل النشر.

## المخرجات

- مجلد Skill صالح للتثبيت.
- بيانات صفحة Marketplace.
- تقرير التحقق والتنبيهات.
- سجل الإصدار والتغييرات.

## ضوابط

- لا تسمح بسر أو مفتاح أو بيانات عميل داخل الملفات.
- لا تمنح صلاحية كتابة إذا كانت القراءة أو المسودة تكفي.
- لا تنشر تلقائيًا؛ المراجعة البشرية إلزامية للمهارات المتوسطة والعالية المخاطر.
