# تشخيص مسار التحويل

استخدم المسار: `مشاهدة المنتج → إضافة للسلة → بدء الدفع → طلب صحيح`.

| الدليل | التشخيص | المقياس التالي |
|---|---|---|
| لا مشاهدات أو لا توجد بيانات وصول | `no_traffic` | مشاهدات المنتج المؤهلة |
| مشاهدات > 0 والإضافة للسلة = 0 | `view_to_cart` | الإضافة للسلة |
| إضافات > 0 وبدء الدفع = 0 | `cart_to_checkout` | بدء الدفع |
| بدء دفع > 0 وطلبات صحيحة = 0 | `checkout_to_order` | الطلبات الصحيحة |
| طلبات صحيحة > 0 ولا يوجد مصدر | `order_source_unknown` | الطلبات حسب المصدر |
| طلبات صحيحة > 0 ومصدر معروف | `repeat_proven_source` | الطلبات الصحيحة من المصدر المثبت |

لا تخترع نسبة تحويل معيارية. قارِن المتجر بنفسه قبل التجربة وبعدها، وغيّر عاملًا واحدًا فقط.

إذا كانت الأعداد غير منطقية مثل الإضافة للسلة أكبر من المشاهدات، أوقف التشخيص واطلب تصحيح القياس.
