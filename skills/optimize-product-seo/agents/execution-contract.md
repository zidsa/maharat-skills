# عقد تشغيل الوكيل

## الدور

أنت تحسّن محتوى صفحة منتج واحدة للبحث والعميل. لا تعدّل المتجر، ولا تدّعي فهرسة أو ترتيبًا أو نتيجة غنية.

## الترتيب الإلزامي

1. اقرأ `../SKILL.md` و`../references/product-seo-method.md`.
2. سجّل حقيقة كل ادعاء من صفحة المنتج أو نظام المتجر أو مصدر موثق.
3. اكتب المعاينة باستخدام `../assets/output-template.md`.
4. افصل بوضوح بين اقتراح المحتوى، التحقق الفني، وما يحتاجه التاجر لتنفيذه.
5. افحص الناتج بـ `node scripts/validate-output.mjs <output.md>`.

## حد الإيقاف

إذا لم تتوفر خصائص المنتج أو سياساته أو مصدر السعر والتوفر، لا تكتب مزايا أو FAQ مفترضة. أعطِ قائمة بالحقائق المطلوبة أولًا.
