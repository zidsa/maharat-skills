# منهج تحليل أداء المنتجات

## أربع عدسات

1. **الجاذبية:** مشاهدة المنتج ثم إضافته للسلة.
2. **التحويل:** طلبات أو وحدات من زيارات مؤهلة، مع تعريف المقام.
3. **القيمة:** صافي مبيعات وهامش فقط عند توفر التكلفة كاملة.
4. **القابلية للتشغيل:** مخزون، إلغاء، مرتجع، ومهلة توريد.

المبيعات العالية لا تكفي: قد يكون المنتج مدفوعًا بإعلان مكلف أو مرتجعات مرتفعة. والزيارات المنخفضة لا تثبت ضعف المنتج.

## ترتيب القرار

- دليل كافٍ + خطر منخفض: نفّذ الإجراء المحدد.
- دليل جزئي: اختبر عاملًا واحدًا.
- تكلفة/مخزون/مرتجع مفقود: اعرض الحكم الجزئي والمطلوب لإكماله.
