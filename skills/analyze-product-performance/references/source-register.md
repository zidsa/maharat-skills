# سجل المصادر

| المصدر | الاستخدام | الرابط |
|---|---|---|
| Zid API docs | حقول المنتجات والطلبات المتاحة حسب الربط | https://docs.zid.sa/ |
| Google Analytics ecommerce | تعريف أحداث view_item وadd_to_cart وpurchase | https://developers.google.com/analytics/devguides/collection/ga4/ecommerce |

بيانات المتجر الفعلية هي مصدر الحقيقة للأرقام. المصادر العامة تشرح التعريف فقط ولا توفر أرقام التاجر.
