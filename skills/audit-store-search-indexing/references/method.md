# منهج العمل

ميّز بين أربع حالات: الاكتشاف، الزحف، الفهرسة، والظهور. ابدأ بالدليل الأقرب للصفحة. لا تستخدم البحث العادي وحده لإثبات الفهرسة. اجمع الصفحات حسب قالب أو سبب مشترك قبل اقتراح الإصلاح. افحص دائمًا الروابط الداخلية وsitemap وrobots/noindex وcanonical وحالة HTTP وإعادة التوجيه.

## درجات الثقة

- **مؤكد:** مدعوم ببيانات أو صفحة أو تقرير مباشر.
- **مرجح:** تدعمه قرائن متعددة لكنه يحتاج تحققًا.
- **فرضية اختبار:** اقتراح مع مقياس نجاح واضح.
- **غير متاح:** لا توجد بيانات كافية للحكم.

## قاعدة القرار

لا تطلب من التاجر حقلًا يمكن قراءته من رابط المتجر أو ملفه المرفق. اطلب فقط ما لا يمكن استنتاجه بأمان، مثل الهدف أو القيد أو الموافقة.
