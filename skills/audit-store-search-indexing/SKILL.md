# مدقّق فهرسة Google

استخدم هذه المهارة للوصول إلى نتيجة قابلة للمراجعة، لا لإنتاج نص عام. اقرأ `references/method.md` قبل التنفيذ وارجع إلى `references/source-register.md` عند الحاجة إلى مصدر.

## المدخلات

- رابط المتجر أو عينة من روابط المنتجات والتصنيفات
- تقرير Page indexing أو URL Inspection من Search Console إن توفر
- رابط sitemap.xml وأي قواعد robots أو noindex معروفة
- أي تغيير حديث في القالب أو الروابط أو النطاق

اطلب فقط المدخلات الناقصة التي تغيّر القرار. إذا تعذر الوصول إلى البيانات، اذكر القيد ولا تخترع بديلًا.

## سير العمل

1. افصل بين الاكتشاف والزحف والفهرسة والظهور؛ لا تعاملها كمشكلة واحدة.
2. صنّف كل ملاحظة: مؤكدة بدليل، مرجحة، أو تحتاج تحقق.
3. راجع الروابط الداخلية وsitemap وrobots وnoindex وcanonical وإعادة التوجيه وحالات HTTP.
4. حدّد أقل إصلاح يعالج السبب، ثم اكتب طريقة تحقق بعد النشر.
5. لا تقل إن Google فهرس صفحة دون دليل من Search Console أو نتيجة اختبار موثوقة.

## حدود الجودة والسلامة

- لا تختلق بيانات أو تقييمات أو مقاييس أو خصائص منتجات.
- لا تضمن ترتيبًا أو ظهورًا أو مبيعات.
- لا تنفذ تغييرًا على متجر يعمل دون موافقة صريحة.
- احذف البيانات الشخصية غير الضرورية من الأمثلة والمخرجات.
- شغّل `scripts/validate-output.mjs` على الملف النهائي إن كانت أدوات shell متاحة.
