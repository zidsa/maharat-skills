# منهج موجز الحملة

## سلسلة الاتساق

`هدف تجاري → جمهور بسلوك → عرض قابل للوفاء → رسالة مثبتة → صفحة هبوط مطابقة → حدث قياس → حد قرار`

إذا انقطعت السلسلة، لا تعوضها بصياغة أجمل.

## هدف واحد

أمثلة: طلبات عملاء جدد، إعادة تنشيط زوار، إطلاق منتج، رفع قيمة السلة، تصريف مخزون محدد، أو إعادة شراء. اكتب المقام والفترة ومصدر الحقيقة.

## دور القناة

حدد هل القناة تكتشف الطلب أو تعيد الاستهداف أو تحول أو تحتفظ. لكل قناة أصل ومقاس وCTA وصفحة هبوط وحدث قياس ومالك. لا تستنتج الإسناد السببي من منصة واحدة.

## بوابة الإنتاج

لا يبدأ الإنتاج قبل توثيق العرض والمخزون والشروط وصفحة الهبوط والمقياس والموافقات.
