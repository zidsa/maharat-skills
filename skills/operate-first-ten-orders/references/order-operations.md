# منهج تشغيل الطلبات

المسار الطبيعي: تأكيد الدفع/شروط الدفع → حجز المخزون → التجهيز → التسليم للناقل → التتبع → التسليم → نافذة ما بعد البيع.

الاستثناء يحتاج فرقًا بين **الحالة المرصودة** و**التفسير**. مثال: «لا توجد حركة تتبع منذ 36 ساعة» حقيقة؛ «الشحنة ضائعة» تفسير يحتاج تأكيدًا.

لا تستخدم مدة عامة لتسمية التأخير. قارن بالموعد الموعود للطلب أو SLA المعتمد، وسجّل المنطقة الزمنية.

لا تختصر الدفع إلى paid/pending عندما يحتاج القرار معرفة التفويض والتحصيل والتسوية والرد والاعتراض والدفع عند الاستلام. لا تخصم المخزون دون SKU وكمية وموقع وحجز قابل للتحقق.

ترتيب الاستثناء يراعي: خطر مالي/سلامة، ضرر عميل قائم، قرب انتهاء الوعد أو المهلة المعتمدة، عمر الحالة، ثم الجهد. لا تنفذ الإجراء من التقرير؛ استخدم مفتاح منع تكرار وتحققًا لاحقًا.
