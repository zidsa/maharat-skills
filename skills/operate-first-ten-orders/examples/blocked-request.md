# مثال توقف صادق

المدخل الوحيد لقطة شاشة فيها أسماء عملاء وعبارة «رتّب الطلبات المتأخرة»، بلا معرفات طلب أو حالات دفع أو حجز مخزون أو وعد تسليم.

النتيجة الصحيحة: لا تنشئ طابورًا ولا تنفذ أو تراسل أحدًا. اطلب إزالة البيانات الشخصية وتصديرًا بمعرف الطلب وحالاته وتوقيتها ومصدر الوعد ومالكي التصعيد. أبقِ النتيجة في **حجب بيانات** حتى تتوفر حقائق كافية.
