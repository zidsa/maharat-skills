# طلب مثال

في 2 أغسطس 2026 الساعة 12:00 بتوقيت الرياض لدي أربعة طلبات دون بيانات شخصية:

- `A-1`: مدفوع، جاهز، ومخزونه محجوز. موعده الموعود 3 أغسطس الساعة 18:00.
- `A-2`: الدفع معلّق، حالته جديد، والمخزون غير محجوز.
- `A-3`: مدفوع، حالته جديد، لكن المخزون غير محجوز.
- `A-4`: مدفوع وقيد التوصيل ومخزونه محجوز، لكن موعده الموعود كان 1 أغسطس الساعة 18:00.

رتّب العمل، وافصل الحالات الطبيعية عن الاستثناءات، وحدد الإجراء والمالك والتحقق اللاحق دون عرض اسم أو جوال أو عنوان عميل ودون تنفيذ أي إجراء خارجي.
