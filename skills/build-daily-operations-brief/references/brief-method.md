# منهج الموجز اليومي

## قبول الأثر

يقبل الأثر إذا احتوى: اسم القدرة، وقت القطع، النطاق، حقيقة مرصودة، إجراء، مالك، موعد، وحالة. إذا غاب أحدها، ضعه في فجوات المصدر.

## ترتيب الأولوية

1. خطر مالي أو سلامة مؤكد.
2. طلب مدفوع لا يمكن الوفاء به.
3. وعد عميل انقضى أو سيتجاوز خلال الوردية.
4. إجراء يحتاج قرارًا لمنع أثر أكبر.
5. تحسين داخلي.

التصنيف لا يعني تنفيذًا. اذكر لماذا سبقت الأولوية غيرها، وما الذي يجعلها مغلقة.

## التسليم

كل بند يحمل `action_key` ومالكًا حاليًا ومالكًا مستلمًا وموعد تحديث. لا تنسخ بيانات عميل داخل الموجز.
