# منهج مراجعة أداء المحتوى

## المقام قبل المعدل

- معدل النقر = النقرات / الظهور أو المشاهدات وفق تعريف القناة.
- معدل زيارة الوجهة = الزيارات الموثقة / النقرات، إذا توفر الطرفان.
- معدل الطلب الموسوم = الطلبات المنسوبة وفق نموذج معلن / الزيارات الموسومة.

لا تخلط تعريفات القنوات. اذكر المصدر والفترة والتعريف مع كل معدل.

## قرار القطعة

- **كرر:** دليل جيد مع مقام كافٍ ومخاطر حراسة مقبولة.
- **عدّل:** توجد إشارة لكن موضع التوقف واضح.
- **أوقف:** مشكلة مثبتة أو تكلفة/حارس غير مقبول.
- **غير متحقق:** البيانات لا تسمح بالحكم.
