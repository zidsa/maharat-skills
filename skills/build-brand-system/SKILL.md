# صانع هوية المتجر

حوّل التموضع المثبت إلى قرارات كتابة وتصميم يمكن لفريق المتجر تطبيقها باستمرار. هذه المهارة لا تعيد بحث السوق ولا تختار تموضعًا جديدًا؛ استخدم `map-market-positioning` أولًا إذا لم يكن التموضع معتمدًا.

## سير العمل

1. اقرأ `references/brand-method.md` و`references/source-register.md`.
2. اجمع سجل المصادر، ومالك الهوية وعلاقته بها ومرجع التفويض، ونتيجة التموضع المعتمدة، والادعاءات التي يملك التاجر دليلًا عليها، والأصول الحالية وقيود القناة.
3. افصل بين **حقيقة مثبتة** و**قرار علامة مقترح** و**معلومة ناقصة**. لا تحول المقترح إلى حقيقة.
4. صغ وعدًا واحدًا قصيرًا مربوطًا بمعرّفات ادعاءات معتمدة. لا تستخدم «الأفضل» أو «رقم 1» أو نتيجة مضمونة ما لم يكن النص نفسه ادعاءً معتمدًا بدليل صالح.
5. ابنِ هرم الرسائل: رسالة أساسية، رسائل دعم، إثباتات، ودعوة واضحة. اربط كل جملة واقعية بمصدرها.
6. عرّف 3–5 سمات للنبرة. لكل سمة: ما نفعله، ما نتجنبه، مثال مقبول، ومثال مرفوض.
7. حوّل الأصول الحالية إلى قواعد مرئية: أدوار ألوان، خطوط، صور، ومسافات ومبادئ مكونات. إذا لم توجد هوية، قدّم نظامًا **مقترحًا** واذكر أساس القرار؛ لا تنسب هوية زد إلى متجر مستقل.
8. اختبر التباين للأزواج النصية الأساسية. لا تعتمد اللون وحده لنقل معنى.
9. أنشئ ملف JSON وفق `references/brand-method.md` ثم شغّل:

```bash
node scripts/validate-brand-system.mjs <brand-system.json>
```

10. سلّم الملخص باستخدام `assets/output-template.md`.

## المدخلات الدنيا

- السوق واللغة واتجاه الواجهة.
- نتيجة تموضع معتمدة: الشريحة، الفئة، البدائل، وسبب الاختيار.
- سجل ادعاءات مع دليل لكل ادعاء.
- الأصول الحالية: اسم، شعار إن وجد، ألوان، خطوط، صور، وأمثلة كتابة.
- اسم مالك الهوية، وهل هي مملوكة للتاجر أو مرخصة، ومرجع يثبت التفويض.
- الأسطح المطلوبة: الرئيسية، صفحة المنتج، الرسائل أو الحملات.
- القيود القانونية أو قيود الفئة والقناة.

## قواعد القرار

- التموضع مدخل، وليس مخرجًا جديدًا لهذه المهارة.
- الوعد لا يتجاوز ما تثبته الادعاءات المعتمدة.
- لا تستنتج الجمهور من لون أو شعار أو ذوق صاحب المتجر.
- اللون المقترح يحتاج سببًا وظيفيًا ومصدر قرار، وليس «لأنه جميل».
- لا تجعل شعارًا أو لوحة ألوان بديلًا عن نظام الرسائل.
- لا تنسخ نبرة أو أصول منافس.
- لا تستخدم لوحة زد الأساسية أو أصولها لمتجر مستقل؛ تشابه القيم لا يصبح تفويضًا.
- لا تنشئ صورة أو شعارًا نهائيًا داخل هذه المهارة؛ اكتب قواعد إنتاج وقبول، ثم سلّم لمهارة إنتاج أصل مرئي منفصلة.
- الحالة `review_ready` ممنوعة عند وجود مجهول يؤثر في الوعد أو ادعاء بلا دليل أو فشل تباين.

## عقد المخرجات

1. سجل المصادر والادعاءات المعتمدة.
2. التموضع المستهلك كما ورد، بلا إعادة صياغة تغير معناه.
3. وعد العلامة وهرم الرسائل وروابط الإثبات.
4. دليل النبرة بأمثلة مقبولة ومرفوضة.
5. نظام مرئي بأدوار لا بقيم مبعثرة، مع نتائج التباين.
6. أمثلة تطبيق على الرئيسية وصفحة المنتج وخدمة العميل.
7. المجهولات والقرارات التي تحتاج اعتمادًا.
8. حالة النظام: `draft` أو `review_ready`.

## تعريف النجاح

يستطيع كاتب ومصمم مختلفان إنتاج مواد متسقة من الملف نفسه، ويمكن تتبع كل ادعاء ومثال إلى دليل أو قرار علامة معلن، دون اختراع ميزة تنافسية.
