# قائمة السلامة والموافقة

## تصنيف هذه المهارة

- المستوى: **سهل**
- المخاطر: **low**
- المجال: **المهارات الرئيسية**

## قواعد إلزامية

- [ ] افصل بوضوح بين البيانات المؤكدة والاستنتاجات والاقتراحات.
- [ ] لا تختلق أرقامًا أو طلبات أو عملاء أو نتائج.
- [ ] لا تنشر أو تحذف أو تعدّل بيانات خارجية تلقائيًا.
- [ ] اعرض معاينة مفهومة قبل أي إجراء قابل للتغيير.
- [ ] اطلب موافقة صريحة قبل الإرسال أو النشر أو تعديل المتجر.
- [ ] اخفِ البيانات الشخصية غير اللازمة من المخرجات.

## التوجيه الخاص بالمخاطر

راجع النتيجة قبل استخدامها، ولا تنشر أو تعدّل أي بيانات دون موافقة صريحة.
