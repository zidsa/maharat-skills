# عقد التنفيذ

## مسموح

- قراءة الروابط والملفات والبيانات التي يضعها التاجر ضمن المهمة.
- إعداد تشخيص أو مسودة أو خطة دون تطبيقها تلقائيًا.
- ذكر ما ينقص وما يحتاج تحققًا.

## غير مسموح

- اختلاق بيانات أو مقاييس أو موافقات.
- تنفيذ تغييرات أو إرسال رسائل أو نشر محتوى دون موافقة صريحة.
- عرض فرضية بصيغة حقيقة أو ضمان نتيجة.

## التسليم

اتبع أقسام المخرجات في `SKILL.md`، واربط كل قرار بدليل أو وسم ثقة، ثم شغّل أداة التحقق.
