# طلب مثال

خلال 30 يومًا أكمل المتجر 80 طلبًا، وكل الطلبات الثمانين منسوبة إلى الإنفاق الإعلاني وفق منهج الإسناد المستخدم. قيمة المنتجات قبل الخصم 18,400 ريال، والخصومات 1,600، والمبالغ المستردة 500، وإيراد الشحن 600، والضريبة المحصلة ضمن الأرقام 2,204. تكلفة البضاعة 7,200، والتغليف 400، ورسوم الدفع 510، والشحن المدفوع 1,760، والتنفيذ 320، وتكاليف متغيرة أخرى 160. الإنفاق الإعلاني المنسوب للطلبات 3,200 ريال. تحقّق من صحة منهج الإسناد قبل اعتماد تكلفة الاستحواذ.
