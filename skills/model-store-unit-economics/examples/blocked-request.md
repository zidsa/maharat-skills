# مثال توقف صادق

طلب التاجر: «مبيعات الشهر 120,000 ريال وإعلاناتي 20,000؛ هل أضاعف الميزانية؟» دون عدد الطلبات المنسوبة، تكلفة البضاعة، الخصومات، المستردات، الشحن، رسوم الدفع أو بيان الضريبة.

النتيجة الصحيحة: لا تحسب ربحًا أو CAC ولا تقترح نسبة زيادة. اعرض قائمة الأرقام الناقصة، وبيّن أن المبيعات وحدها لا تثبت مساهمة موجبة، ثم أجّل قرار التوسع حتى تتوفر تكلفة الطلب ومصدر إسناد الطلبات المدفوعة.
